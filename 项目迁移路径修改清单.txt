四、建议修改：scripts\build_vs2022_qt.ps1
------------------------------------------------

文件：项目根目录\scripts\build_vs2022_qt.ps1

1. Qt 自动探测

原来：

    if (-not [string]::IsNullOrWhiteSpace($env:QT_MSVC2022_64)) {
        $QtPrefixPath = $env:QT_MSVC2022_64
    } else {
        $QtPrefixPath = "C:\Qt\6.7.3\msvc2022_64"
    }

改为：

    if (-not [string]::IsNullOrWhiteSpace($env:QT_MSVC2022_64)) {
        $QtPrefixPath = $env:QT_MSVC2022_64
    } elseif (Test-Path -LiteralPath "D:\QT\6.7.3\msvc2022_64" -PathType Container) {
        $QtPrefixPath = "D:\QT\6.7.3\msvc2022_64"
    } else {
        $QtPrefixPath = "C:\Qt\6.7.3\msvc2022_64"
    }

    } elseif (Test-Path -LiteralPath "E:\Libs\OPENCV3\opencv\build\x64\vc15\lib\OpenCVConfig.cmake" -PathType Leaf) {

六、每次从其他电脑迁移到当前电脑后的操作顺序
------------------------------------------------

1. 将项目复制到当前电脑。

2. 不要复制以下目录；如果已经复制过来，应先关闭 Visual Studio，再删除：

    .vs
    out
    build
    vcpkg_installed

这些目录包含原电脑的绝对路径、CMake 缓存、编译器路径和第三方库安装信息。

3. 按本清单第二节修改 CMakePresets.json。

4. 按本清单第三节修改 CMakeUserPresets.json。

5. 如需使用项目构建脚本，按第四节修改 build_vs2022_qt.ps1。

6. 确认以下文件真实存在：

    D:\QT\6.7.3\msvc2022_64\lib\cmake\Qt6\Qt6Config.cmake
    C:\vcpkg\scripts\buildsystems\vcpkg.cmake
    E:\Libs\OPENCV3\opencv\build\x64\vc15\lib\OpenCVConfig.cmake
    C:\Program Files\Allied Vision\Vimba X\api\bin\VmbCPP.dll

7. 使用 Visual Studio 2022 打开项目根目录。

8. 在配置下拉框中选择：

    qt-debug

9. 等待首次 CMake 配置和 vcpkg 安装完成。首次安装会创建：

    项目根目录\vcpkg_installed\x64-windows

10. 执行“全部生成”。

11. 正常情况下主程序生成在：

    项目根目录\out\build\qt-debug\UI\i2r_rlc.exe


七、命令行备用编译方法
----------------------

在项目根目录打开 PowerShell，执行：

    powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\build_vs2022_qt.ps1 -BuildDir out/build/qt-debug -Configuration Debug

成功时最后应显示：

    [PASS] CMake configure: exit code 0
    [PASS] CMake build: exit code 0
    PASS: 20  FAIL: 0


八、原始报错的直接原因
----------------------

迁移后，项目所需的本机环境变量全部为空，导致 CMake 实际得到：

    CMAKE_TOOLCHAIN_FILE=/scripts/buildsystems/vcpkg.cmake
    OpenCV_DIR=
    VCPKG_INSTALLED_DIR=
    VCPKG_MANIFEST_INSTALL=OFF

其中 /scripts/buildsystems/vcpkg.cmake 并不存在，而且又关闭了 vcpkg manifest 自动安装，
因此 CMake 无法生成完整构建系统，更不可能进入正常编译。


九、注意事项
------------

1. 路径写入 JSON 时统一使用正斜杠“/”，不要使用未转义的单个反斜杠“\”。
2. OpenCV_DIR 必须指向包含 OpenCVConfig.cmake 的 lib 目录，不能只写 OpenCV 根目录。
3. QTDIR/CMAKE_PREFIX_PATH 必须指向 msvc2022_64 根目录，不能指向其 bin 目录。
4. VCPKG_ROOT 必须指向 C:/vcpkg，而不是 C:/vcpkg/scripts。
5. 当前配置使用 OpenCV 3.4.x，不要直接换成 OpenCV 4.x。
6. 当前 Debug 构建需要 opencv_world345d.dll；当前电脑上已经存在。
7. CMake 的 CMP0144/FLANN 提示是开发者警告，不影响本次配置和编译成功。
