# 在线纠偏回到论文算法框架，以检测轨迹主导位置修正

2026-10-26，用户确认在线纠偏回到论文中的相关滤波跟踪、虚实信息融合、模板更新与恢复框架，并直接以刘涛在杨家林工作基础上的方案为主要实现目标，包括三模板双特征联合训练及相应跟踪机制。杨家林方案用于理解基础机制和对照，不要求先完成其独立实现再引入刘涛方案。当前原图几何验收与历史续接路径不再被默认作为继续修补的主线；几何提取作为辅助校核或补充。融合参数、遮挡恢复策略及具体实现仍待讨论。

工件实际摆放与仿真工件位姿不一致时，仿真绝对位置可能不准确，但斜率、形状等信息仍可能提供帮助。可靠的当前图像观测主导位置校正，允许根据已确认观测估计局部虚实偏差；仿真位置、形状和运动趋势分别评估，不因位置失配整体弃用仿真，也不因使用仿真而默认其方向或位置必然准确。不能仅因实测偏离仿真位置而持续拒绝，也不能用固定融合将结果长期拉偏。

跟踪输出、模板更新和独立几何证据资格分别判断。相关响应质量、历史一致性和必要几何校核共同参与决策，不强制每帧完整双侧母材拟合作为所有输出及模板更新的统一前提。正常观测可以更新模板，异常实拍观测避免污染模板，仿真模板参与遮挡恢复。

检测形成的空间轨迹主导 TCP 位置修正。前置传感器检测点按运动进度供 TCP 后续跟随，不能要求 TCP 立即追逐画面最新点；示教轨迹和轨迹匹配提供姿态、方向与适当平滑，不能长期把正确检测结果拉回原有示教轨迹。

经过遮挡后，一旦确认重新找到同一条真实焊缝，位置估计应尽快纠正。机器人运动平滑由空间轨迹与控制环节处理，不能通过缓慢移动错误检测点代替控制平滑，也不能让错误历史预测持续否决已恢复的可靠观测。具体重捕获判据、校正速度及控制平滑参数尚未确定。

普通预焊遮挡期间利用有效图像结构、历史信息和可信仿真信息保持连续估计。持续显示估计点与持续授予控制资格分开：当图像持续无法提供有效信息、仿真位置也不可信时，UI 可以保留带低置信状态的估计点，控制端先消费已有可靠前视轨迹；可靠轨迹耗尽且仍无法恢复时进入停止作业流程，不允许仅凭持续显示的估计点无限驱动机器人。

严重失测后的停止作业包括停焊和机器人受控停止运动，不能仅停止发送纠偏量而让机器人继续沿原示教轨迹焊接。停止后不因重新检测到焊缝而自动恢复运动，需要人工确认后重新启动。停弧、运动停止及状态确认的具体顺序仍须核对机器人端 JBI 与通信接口，不将停止上位机更新等同于设备已停止。

用户特别要求谨慎确定严重失测门槛，避免正常可检测场景被拒绝并导致测试无法进行。单个检测门限失败、缺少完整双侧几何、仿真位置失配或若干帧未取得独立实测资格，均不能直接等同于严重失测；也不能只按连续拒绝帧数或过严固定超时触发停机。具体判据须综合有效图像证据、跟踪及重捕获结果、估计可信程度和可用前视轨迹，并通过正常、反光、预焊遮挡及真实失测场景验证。正常可检测场景不得被误判停机是验收要求；真实失测场景也必须验证能触发停止。可靠性、重捕获及持续性参数尚未确定，平均／最大误差验收目标不直接充当在线停机门限。

本轮实现范围集中于三模板、HOG／灰度双特征联合训练，仿真辅助的位置估计、模板更新与遮挡恢复，以及检测结果到空间轨迹、TCP 跟随的必要对接。坡口宽度调速和工件在线点云 ICP 的进一步优化另行处理；关闭工件在线点云 ICP 时，基础焊缝跟踪仍应具备准确、稳定、连续输出能力。

准确性、连续稳定性和最终跟随效果分别验收：检查可见接缝定位、遮挡期间合理估计及恢复校正，检查预焊前中后持续输出与漂移跳变，再检查空间检测轨迹和 TCP 实际运动误差。当前阶段空间精度目标由用户确定为平均位置误差不超过 2 mm、最大位置误差不超过 5 mm，相对独立测得的真实焊缝轨迹评价；检测轨迹与 TCP 跟随轨迹分别统计，预焊段单独报告，原图像素定位误差另行检查。这些数值是待验证的验收目标，不直接作为逐帧拒绝门限，也不代表当前程序已经具备该精度。仅有持续显示不代表通过验收，论文实验数值不直接作为本项目的精度承诺。

依据为用户在本轮讨论中对 Q1、Q2、Q3、Q5、Q6、Q7、Q8、Q9、Q11 的确认，Q4 明确选择直接以刘涛方案为主要实现目标，Q10 将平均／最大位置误差目标调整为 2／5 mm，以及 Q11 补充的防止正常可检测场景误停机要求。本文记录目标与取舍，不表示当前程序已实现或已通过验证；本轮不修改业务代码。
