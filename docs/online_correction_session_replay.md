## 可验证会话边界

单独运行现有 runtime tracking flow 可执行文件的 `--normal-session-replay-contract`。入口复用生产 Vision、在线控制和 RobotComm worker 的公开会话接口；外部图像/仿真输入和设备传输为合成夹具，不用 Python 再实现检测、投影或队列策略。这个确定性单线程组合用于检验业务会话，线程调度与迟到事件继续由已有 coordinator 专项覆盖。

输入包括有序原始灰度图、曝光 ID/时间、冻结机器人位姿、标定和同曝光仿真条纹；每个曝光都实际调用生产检测器。测试设置相机平面偏置和激光平面距离相互抵消，使中心空间点在 TCP 前方 10 mm；机器人随后沿 X 推进，完整队列通过真实异常处理和跟随器消费。初扫、O=4/5 回包、P001 到位、STARTCOR、普通 P、最终 P 回包、检测清零与主程序停止均通过真实状态机。

工件在线点云 ICP 在此组合中明确不实例化、不写回；控制层轨迹 ICP 明确开启并保留实测参考。二者不能混称一个 ICP 开关。合成已知接缝位置只用于外部断言，不传入生产代码作为真值。不把这组输入称作现场连续曝光，不以其结果宣称真实 TCP 的 2/5 mm 精度。

## 统一报告语义

现有 recorder 各诊断文件保留。启用 visionDiagnostics.enabled 时新增 unified_session.jsonl，按 recorder 接收顺序给事件编号；观察、释放批次、控制目标、命令和回执保存在同一会话目录。

- 观察记录会话、曝光、参考版本、实际活跃算法、点来源与资格、冻结姿态和投影结果；无效曝光也保留。
- 释放记录真实生产批次与空间目标，控制记录实际使用的几何，命令记录待发内容，回执记录实际 request/response。待发和实际发送不是同一件事；实时命令可能被通信层合并。
- 原始检测样本携带冻结的 session_id、frame_id、reference_revision，经坐标转换、缓冲、释放保持；release.source_exposure 记录此身份。模型重采样不与曝光一一对应，保持 null。control_target 分别保留实际队列首点及方向端点的 source_exposure、direction_source_exposure；预测参考两者为 null。实时待发命令通过 target_generation 关联该目标，control_update 本身没有单一曝光来源，保持 null。顺序编号和待发目标不证明设备执行；通信合并后的实际回执与后续 TCP 仍须单独关联，禁止用最近图像补造来源。
- 报告文件操作失败沿用 recorder 原有诊断错误路径，不改变检测或控制决策。

真实连续预焊后半段及其曝光姿态、独立焊缝参考不足的限制仍然保留。后续任务应继续扩展同一会话入口，不以稀疏图、预测点或当前 TCP 代替缺失证据。

## 仿真先验失配与报告边界（任务 04）

正式论文路径把仿真位置、局部形状和实际图像观测分开处理。仿真焊点移出图像或在图内有偏差时，可将仍可用的局部折线平移到原图匹配得到的取样锚；初始化优先当前原图几何及图像特征提案，以当前实拍建立模型和身份，仿真外观只作为辅助模板。候选只确定 MKCF 初始化 ROI，后续仍须通过当前图像响应、图像身份及空间投影验收，不能直接成为测量或独立几何点。2026-10-27 按用户方案1移除了虚实灰度相关 `0.7` 的两处仿真准入限制，不再用这一分数直接判定方向错误或撤下有效折线。基本输入有效性检查和原始参考元数据保留；不得把取样锚写回工件位姿。

`unified_session.jsonl` 的 `observation.simulation_prior` 与同曝光的公开算法诊断对应，像素坐标均为原始图像坐标：

| 字段 | 含义与不可用语义 |
| --- | --- |
| `source_point_px` | 输入仿真焊点 `[x, y]`；参考没有该点时为 `null`。不因模板重定位而改写。 |
| `position_in_image` | 原始仿真位置是否落在当前图像内；不代表该位置准确，也不授予观测资格。 |
| `shape_available` | 本曝光是否存在通过基本有效性检查、可用于取样的仿真局部形状；不代表虚实灰度相似度、方向或绝对位置已被实测证明。 |
| `template_rebased` | 有效仿真外观是否在其他取样锚渲染；不表示工件位姿已更新。 |
| `template_point_px` | 有效仿真外观的实际取样锚 `[x, y]`；形状不可用时为 `null`，不得填入预测点代替。 |

这些字段用已有会话、曝光和参考版本关联，仅说明仿真输入与外观取样。实际输出、点来源及独立几何资格仍以同一观察记录原有字段为准。没有算法诊断的观察不补造该对象；释放事件的 `source_exposure` 按本页统一报告语义保留原始样本身份，未知时保持 null。

同一生产会话入口增加图外平移、图内偏差、方向错误、初始参考暂缺四类契约，保持全部 28 次原图/曝光姿态输入与评分，不跳过参考失配曝光。其自动化验证仅覆盖合成会话中的检测、投影、完整队列、通信和结束流程，不代表真实 TCP 平均 2 mm、最大 5 mm 的现场精度。

刘涛式（3-43）至（3-46）在原始图像观测验收后复用现有二维 CFilterKalman：先验为当帧仿真位置加上上一次可靠新曝光支持的局部虚实偏差，当前相关观测或独立几何作为测量，H=I。首个可靠观测只建立偏差，不能用同帧观测构造同帧先验冒充融合。噪声沿用滤波器已有上下限并按当前图像质量映射，不采用固定位置混合权重；可靠图像仍须通过原有验收，先验不一致仅撤销融合资格，不能因此拒绝图像或拉回仿真位置。

偏差仅在同一焊缝、同一参考版本、单调新曝光内使用。正常背压造成的曝光编号跳跃不等于失效；明确缺图/无效输入、参考缺失、观测拒绝、仅肩部估计、版本或焊缝切换会清除旧依据。新可靠观测重新建立偏差，且偏差始终由融合前原始已验收观测刷新，不能把融合结果反馈成永久标定。当前图像训练 ROI 仍在原始观测处，工件位姿不写回。内部 MKCF 的 KcfOnly 只负责保持原始相关观测和模板采样；正式位置融合在观测资格判定后的独立步骤执行。

统一观察记录新增 position_fusion 对象：applied 和 trusted_prior 分别表示实际融合及先验资格；observation_px 是融合前已验收当前图像测量，未接纳时为 null；prior_px、local_bias_px 与 gain 只在实际融合时保留二维数组，其余情况为 null。最终像素仍在同条观察的 pixel，冻结姿态与 space_parent_tcp_mm 用于追踪同曝光空间结果。这些字段是数值与来源诊断，主验收仍为完整会话的可靠输出、独立空间误差和不被错误仿真长期拉偏；滤波增益大小不能单独证明效果。

同一入口另以中途仿真偏差跳变和单调跳曝光编号的完整 28 次输入验证局部偏差过期与正常背压行为。合成会话不能替代现场精度与实时性能验证。

## 在线会话与参考生命周期

论文跟踪路径在处理尺寸或缝号变化前检查曝光单调性。重复或倒序曝光不能借改变参考元数据清空模型、训练模板或创建新的当前图像观测。仿真 DTO 暂时无效时，不将未知缝号覆盖为既有目标身份；同一目标的有效参考恢复后可以继续使用当前图像模型。

参考版本标识随曝光冻结，统一报告保留每个输入自己的版本。CAD 版本更新或绝对位置变化不是独立实测焊缝运动；完整会话合同同时核对切换前后图像位置、空间结果和控制队列，不以报告字段正确代替位置正确。

coordinator 发出公开图像结果信号后，会再次核对当前会话。UI 在该回调中普通停止并显式重启时，已经停止的旧结果不能继续进入新 Control 队列；新会话使用新曝光建立独立目标。普通检测重启与已请求运动 HOLD 后的作业恢复不同；后者保持锁存，不由图像恢复、重连或普通启动调用自动解除，人工恢复及停弧协议仍需独立明确。

对应专项入口为 `--session-lifecycle-contract`、`--session-new-exposure-contract`、`--liutao-repeated-exposure-session-contract`、`--liutao-invalid-reference-session-contract` 和 `--liutao-reference-revision-session-contract`。它们使用生产检测、投影、控制及模拟设备边界，不代表真实连续预焊数据或现场 TCP 精度已经验收；逐次构建和运行证据保留在任务记录中。

## 反光、预焊与定位恢复（任务 05、06）

PSR 使用完整响应图统计。按实际响应模板数分别积累至少30次可信焊前响应形成 Welford 正常统计，正式在线冻结对应分布并按论文双侧3σ判别，避免缺仿真时单模板统计永久停在零，或混用单/三模板的尺度；统计未成熟时用当前目标外观支持判断，不能把样本不足当成失测。异常实拍不提交给可信模板，复用仿真外观替代训练；这不赋予独立几何资格。完整身份块先匹配矩形外观，只有当前外观不完整时才匹配原条纹支持区域，以减轻附加亮支系的干扰。双肩可见但中心被遮挡时输出受图像约束估计，中心与肩部资格分开记录。

局部多峰必须先有当前图像支持，且确实是原始相关图中的局部极大值；重复抑制后产生的斜坡边界不算新峰。2026-10-27 的现场回归显示，旧运动量曾同时影响肩部搜索中心和候选排序，使正常响应被错误肩部覆盖。完整当前响应优先决定搜索窗口；仅在外观不完整且相邻同来源运动可用时，复用该运动寻找当前图像肩部。局部峰排序也只使用逐帧更新的同来源位移，缺图/拒绝或几何与外观来源切换时不用旧差分。肩部约束位移不依赖是否提交实拍训练，不能让模板未训练变成运动量永久不更新。当前原图几何可直接纠正取样锚，拒绝当前响应时再调用既有分帧几何搜索重建跟踪器。亚像素响应修正避免逐帧整数峰累计滞后。局部身份搜索不是已证明覆盖任意大偏差的全图重捕获，曝光间隔明显变化的现场行为仍需实测。

空间队列只按机器人实际运动消费，不按调用次数删点；仍在前方的点不能仅因横向残差使方向余弦接近零而提前消费。定位及时纠错与机器人增量限幅分别负责，完整队列与实际 P 使用的几何均保留。组合会话继续包含仿真位置跳变、反光、预焊及第一帧清晰图像恢复，不能用最后一帧正常掩盖恢复迟滞。

## 严重失测的控制边界（任务 08）

Vision 的生产结果始终携带定位尝试、当前图像支持、受图像约束估计和恢复结果，安全决策不依赖可选诊断。只有当前定位与恢复失败、无当前图像支持且可靠前视末端耗尽，Control 才请求作业保持；缺独立几何、仿真失配或固定若干帧拒绝不单独触发。真实未释放样本仍计入有限可靠范围，估计和控制参考预测不能扩展该范围。正式在线首帧即丢失时，按正向焊接顺序关联全部初扫实测点，取最远已测末端提供有限范围；反扫最后一帧在起点，不能替代前向覆盖末端，整条平移 CAD 不是可靠观测。

末端判断先沿既有有序路径逐段关联机器人与可靠末端，再判末可靠方向的到达/越过，避免回折末段切平面穿过早期支系导致误停。该关联用于区段身份，不把 CAD 当焊缝真值；闭环、退化方向与大幅偏离仍须保留验证限制。作业停止在公开回调前锁存，runtime 在普通 Error 会话失效前处理当前会话停止请求，停止后迟到结果不再产生运动命令。

统一报告保留 observation.localization_evidence、control_update.request_operation_stop、实际 N 请求与新 D 反馈。HOLD 从 Pending 到 HoldConfirmed 仅表示新 D.sHold 确认；不代表已停弧或机械零速。图像恢复不自动恢复作业。完整停止语义另见 [受控停止](online_correction_controlled_stop.md)。

## 评分与现场证据边界（任务 10）

### 上位机实时命令与回执来源

实时P的生成事件与实际合并发送后的回执保留同一可选local_trace（session_id、command_id及可选target_generation）。command_id由控制线程在recordUpdate与公开emit共用快照上赋值，跨configure/reset不复用；RobotComm只从实际选中的P复制来源到回执，并分配本地local_transaction_id，不能按最新到达命令、请求文本或最新曝光反推。相同增量也可属于不同命令。明确属于旧会话的回执不进入新会话控制或记录；无来源的legacy调用继续兼容，并记录null，不能补造身份。

这些字段不进入P/D线协议，local_transaction_id和target_generation均不是控制柜执行序号。回执统一保留execution_semantics=unknown_execution；可解析D记delivery=response_received，未收到有效D记delivery_unknown。现有transport在接收失败后可能仍将sent置false，这不能证明命令未发送或未被执行。此片仅补齐生成P→合并后实际选中P→事务D的上位机来源；合并丢弃明细、独立发送/接收时刻和后续TCP因果关联仍需后续实现与验证。

同一测试入口输出 SESSION_SCORE JSON，保存所有输入曝光及夹具真值、有效/缺测/估计数量，分别统计全程和预焊区间的空间检测误差、原图像素误差、误停及漏停。最大值为实际最大值；无效或未关联样本保留为缺测，不能悄悄删去。该 JSON 属于合成原图生产链测试证据；实际 TCP 精度明确为 null，现场精度验收为 false。不能据此宣称检测或 TCP 的现场平均2mm、最大5mm已经通过。
