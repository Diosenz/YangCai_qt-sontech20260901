# 在线纠偏的工件局部定位

## 行为与边界

在线纠偏进入 `OnlineRunning` 后，独立的 `online-local-registration` 线程从已经完成主视觉处理的同帧上下文采样。复用当前相机图像、冻结的机器人状态和 RobotSim 三维激光线，不增加逐帧仿真请求，不改变机器人 O/P 指令与轨迹 ICP。初始反向扫描、离线纠偏、普通 IBVS 和全局定位不启用本支路。

真实表面线复用现有 Gabor/Steger 全局采线实现，但在独立实例和线程中运行。真实点保留投影器输出的变位机 TCP 坐标，不再加回 `toolTcpInLastLinkMm`；虚拟线必须明确以同一工件父级 TCP 对象 `workpiece_parent_id` 为参考，单位均为 mm。当前场景的参考对象 1063 相对末节已有 Z=231 mm 偏移，不能将其误认为末节原点。调度器核对参考 ID 与父级 ID 一致，场景配置还必须保证该父级的几何定义与投影 TCP 一致。不把间隙检测内部点云或焊缝单点轨迹当作工件表面。

真实/虚拟局部窗口交给现有 `LocalizationLocalCorrectionPipeline`，使用 XYZ 平移及绕 Z 旋转约束。输出的 `virtualToRealCorrectionTransform` 左乘工件当前相对父级位姿，随后 `SET_POSE(relative=true, updateChildren=true)`，再回读世界位姿确认。场景 XML 和工件文件不写入。

## 调度与参数

运行时启动时读取 `config/digital_twin/online_local_registration.ini`。这些值是本次实现采用的保守初值，尚不代表经过真实工件的参数标定。

| 项目 | 默认值 |
|---|---|
| 局部图像采样最短间隔 | 200 ms |
| 配准完成后的最短冷却 | 2000 ms，模型写回清窗仍保留冷却 |
| 有效窗口 | 8～16 帧 |
| 每侧送入配准的最大点数 | 512 |
| ICP 最大迭代 | 40 |
| ICP 最大对应点距离 | 默认 5 mm；在线界面可在 0.1～10 mm 调整 |
| 求解后验收耗时预算 | 300 ms |
| 单次修正上限 | 平移分量模长默认 5 mm，界面可调至 10 mm；旋转角 1° |
| 平均最近邻残差验收 | 至少改善 5%，且修正后不超过 2 mm |
| 机器人状态最大年龄 | 500 ms |
| 候选结果最大年龄 | 从本次采样派发起 1500 ms |

采样和 ICP 最多只有一个任务在途。繁忙时跳过采样，不排队、不阻塞主 KCF 或机器人通信线程。窗口帧数、窗口年龄、每帧和整窗点数分别有界；所有求解批次均清窗。近共线或覆盖不足的窗口拒绝写回。失败后同样冷却，防止持续重复求解。

配准前后残差计算是 O(N×M)，因此在进入 pipeline 前先限制两侧点数，而不只依赖 PCL 内部抽稀。

## 写回与生命周期

写回只在主视觉和同帧 RobotSim 查询均空闲时提交，暂缓新的同帧查询；相机继续采集，保留最新待处理帧。成功后推进模型代次、清除旧窗口和旧待处理帧，下一份仿真参考从新模型生成。不会像参考工程 IBVS 路径那样发送机器人保持位置指令。

停止、重启、在线阶段切换、Vision 暂停/恢复、RobotSim 重连/切换场景、投影或标定配置变化，以及机器人运行/保持/模式改变都会撤销旧代次。机器人快照过期时清窗，写回读取位姿后再次核对原子代次和快照截止时间。旧任务返回不得重新启用会话或写入新工件。

读取失败立即返回；局部写回的前置读取超过 150 ms 时不再继续发送位姿修正。SET_POSE 已发出但回读失败时，不重复应用同一修正，停用本轮自动工件更新，主纠偏流程继续。需重新开始在线会话才能恢复自动更新。

## 性能观测与限制

运行日志中的 `[在线局部定位]` 记录实际窗口、点数、采集及处理耗时、求解耗时、配准前后残差、拒绝原因和写回耗时。程序启动还输出本次启用状态及频率参数。

300 ms 是求解返回后的验收门槛，现有 PCL 没有硬中断接口；不能把它描述成计算一定在 300 ms 内结束。任务独立于 UI、KCF 和机器人通信，仍会使用 CPU，真实设备上的帧间隔和 CPU 占用需联调测量。

写回仍使用同一个 RobotSim 通道，期间检测叠加刷新会等待位姿事务；它不是保证零抖动的异步网络协议。故障时单次请求仍受 `robotsim_endpoint.txt` 中 `request_timeout_ms` 控制，可能出现约一个请求超时的等待。默认 1000 ms。超时后不连续重试自动工件更新，不能把原始相机继续刷新等同于检测叠加完全不中断。

## 在线界面热调整与显示稳定性

在线纠偏页面提供独立的“开启在线 ICP 局部定位”开关，以及“自动卡尔曼 / 手动比例 / 仅 KCF”三种位置融合策略。手动模式的仿真、KCF 百分比互补，总和为 100%；这是固定权重融合，不是修改自动 Kalman 的协方差。默认仍使用原有自动 Kalman。局部定位初始开关取自 INI；界面调整作用于当前运行时，不写回参数文件。

启动前和运行中均可调整。融合参数通过视觉线程队列按后续帧应用，仅清理滤波历史，保留 KCF 模板和跟踪窗口；已在处理的帧继续使用其原参数。在线融合策略仅应用于正式在线纠偏关联帧，离线检测保持既有默认行为。

关闭局部定位时同步撤销代次令牌，清空候选与窗口；重新开启后重新积累点云，保留频率限制。已发出的 SET_POSE 无法撤回，事务须等回读完成；同会话内即使开关改变，也不能丢弃未知写入结果或重置故障锁。启动 INI 无效时禁止通过开关绕过停用。

在线坐标、状态、P001、同步错误和 RobotSim 状态区使用固定显示几何，长文字不再撑高布局，完整内容保留于提示。正常同步阶段合并为“运行中”；普通 robot state accepted 心跳不覆盖业务状态。坐标仍保持原有有效值锁存与过期提示，不改变控制输入，不将失效参考冒充有效参考。

## 2026-10-20 局部 ICP 的 TCP 参考系修复

本次现场记录关联的 RobotSim 端口为 55210，活动场景为 test31.xml。运行日志确认工件父级参考对象 1063 相对 Link2 已有 Z=231 mm 的 TCP 安装偏移。旧局部入口却将真实 PositionerTcp 点再加一次 toolTcpInLastLinkMm，与保持 1063 参考的虚拟点发生坐标系混用。

修复仅移除局部 worker 的这次加法；投影器内从末节到 TCP 的正常转换保留。局部 virtualToReal 修正仍表达在共同的工件父级参考系，并直接左乘工件父级相对位姿。全局定位、轨迹 ICP、匹配阈值、采样频率和场景对象 ID 不随此修复改变。

回归以真实图像采线入口构造：末节 Z=1000 mm、TCP 安装偏移 Z=231 mm，因此真实 TCP Z=769 mm；仿真参考 TCP Z=768.75 mm，应产生 Z 方向约 +0.25 mm 的虚拟到真实修正。先仅纠正测试参考坐标，在旧代码上复现配准前残差 231.252 mm 和 ICP 未收敛；该用例同时覆盖后续模拟写回及回读。另覆盖零偏移、XYZ=(12,-7,231) mm 与 Z=150 mm 安装偏移，防止以硬编码减去231替代正确的坐标约定。

本次没有修改工件 ID；现场配准验收与真实场景写回效果仍需复测，不以合成用例通过替代现场结果。修改前备份和构建、回归日志位于 .codex_backups/local_icp_tcp_frame_20261020/。

## 在线 ICP 对应点距离调整

开启“在线 ICP 局部定位”时显示“最大对应距离(mm)”，关闭时隐藏该行。默认 5 mm，上限 10 mm，下限 0.1 mm，支持运行中调整；这是 ICP 搜索对应点的距离，不是配准后的残差验收，也不会扩大原有工件移动限幅。

初始值从 online_local_registration.ini 的 max_correspondence_distance_mm 读取（缺省5）；界面调整仅作用于当前运行时。参数变化时同步撤销旧代次与候选，并在局部线程排队清窗、更新参数；已执行的求解仍计入冷却，避免反复调参绕过频率限制。正在处理的不可撤回位姿事务继续按原有回读和故障规则完成，不因调阈值清除保护。

新增阈值回归覆盖默认/上下界/非法值、UI随开关显隐及无反馈热调、运行时参数独立性。另以 6.25 mm 的合成表面偏差区分 5 mm 与 10 mm 搜索范围，并验证匹配成功后仍受原有 2 mm 工件移动限幅约束。备份与构建、测试日志位于 .codex_backups/local_icp_threshold_20261020/。

上述坐标修复与可调距离功能已在原有 VS2022/MSVC Debug 构建中验证：主程序生成成功，online_correction、online_fusion_controls、online_local_registration、main_widget_panel、offline_correction、localization、digital_twin 共 7 项回归通过。合成图像回归的初始最近邻残差包含真实提取与采样偏差（约1.048 mm），修正后约0.026 mm；它不是现场点云重放。现场真实设备验收尚未执行，历史运行时/同帧同步失败未在本轮重复运行或修改。

## 单次平移修正上限调整

在线局部定位面板增加独立的“最大平移修正(mm)”选项，默认 5 mm，允许 0.01～10 mm；仅开启局部 ICP 时显示，可在启动前及运行中调整。它使用修正矩阵平移分量的三轴合成长度，超限时整次拒绝，不截断，也不表示累计修正预算。

“最大对应距离”与“最大平移修正”分别决定搜索范围和位姿结果能否写回，两者互不覆盖。放宽平移上限后，仍必须通过配准后残差不超过 2 mm、至少改善 5%、旋转及耗时等原有质量检查。此前明确设 2 mm 的搜索范围回归保留，用于证明这两个参数独立；当前默认平移上限已改为 5 mm。

初始值取自 online_local_registration.ini 的 maximum_translation_mm，默认配置改为 5，合法上限同步改为 10。界面变化只作用于当前运行时；热调同步撤销旧代次和候选，并排队清空窗口、更新局部线程参数，在途任务、故障保护及冷却规则不变。工件对象 ID 和全局/轨迹定位链路未修改。

专项回归覆盖默认值/上下界/非法值、启动配置读取、运行时独立热调、界面显隐和无反馈更新；对同一 6.25 mm 合成偏差验证平移上限 5 mm 拒绝、10 mm 可通过，并验证残差或改善不足时仍拒绝。修改前备份与构建、测试日志保留在 .codex_backups/local_icp_translation_20261020/。
