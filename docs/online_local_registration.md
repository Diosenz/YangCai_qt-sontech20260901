# 在线纠偏的工件局部定位

## 行为与边界

2026-10-23 方案 A 将在线纠偏的反向初扫及正式跟随改为“当前原图决定测量输出”。本页末尾“方案 A：原图测量边界”取代这两个入口先前关于仿真种子、肩部预测补点和坐标融合的说明；离线和其他未启用入口继续原有实现。工件位姿更新的事务、后验及保留策略不变。

2026-10-22 最新用户策略：正式在线纠偏禁止自动回退工件位姿。后验失败或超时保留当前已回读位姿，结束事务后清窗并继续下一轮 ICP。以末尾“取消在线自动回退”章节为准；前文自动恢复与恢复计数保留为历史证据。

2026-10-22 新增“有界仿真辅助接缝”和“已有可信位姿后的表面辅助更新”。本页末尾同日章节（包括反光/预焊点后的图像几何续接修复）说明当前接线；早期“所有更新都必须存在独立焊点”和“无限期像素续接”的描述只保留为历史版本，不覆盖同日新边界。

在线纠偏进入 `OnlineRunning` 后，独立的 `online-local-registration` 线程从已经完成主视觉处理的同帧上下文采样。复用当前相机图像、冻结的机器人状态和 RobotSim 三维激光线，不增加逐帧仿真请求，不改变机器人 O/P 指令与轨迹 ICP。初始反向扫描、离线纠偏、普通 IBVS 和全局定位不启用本支路。

真实表面线复用现有 Gabor/Steger 全局采线实现，但在独立实例和线程中运行。真实点保留投影器输出的变位机 TCP 坐标，不再加回 `toolTcpInLastLinkMm`；虚拟线必须明确以同一工件父级 TCP 对象 `workpiece_parent_id` 为参考，单位均为 mm。当前场景的参考对象 1063 相对末节已有 Z=231 mm 偏移，不能将其误认为末节原点。调度器核对参考 ID 与父级 ID 一致，场景配置还必须保证该父级的几何定义与投影 TCP 一致。不把间隙检测内部点云或焊缝单点轨迹当作工件表面。

真实/虚拟局部窗口交给现有 `LocalizationLocalCorrectionPipeline`，使用 XYZ 平移及绕 Z 旋转约束。输出的 `virtualToRealCorrectionTransform` 左乘工件当前相对父级位姿，随后 `SET_POSE(relative=true, updateChildren=true)`，再回读世界位姿确认。场景 XML 和工件文件不写入。

## 调度与参数

运行时启动时读取 `config/digital_twin/online_local_registration.ini`。当前值按 2026-10-20 现场日志调整为摆放偏差联调初值，尚不代表经过真实工件的参数标定。

| 项目 | 默认值 |
|---|---|
| 局部图像采样最短间隔 | 200 ms |
| 配准完成后的最短冷却 | 2000 ms，模型写回清窗仍保留冷却 |
| 有效窗口 | 8～16 帧 |
| 每侧送入配准的最大点数 | 512 |
| ICP 最大迭代 | 40 |
| ICP 最大对应点距离 | 默认 10 mm；在线界面可在 0.1～10 mm 调整 |
| 求解后验收耗时预算 | 2500 ms；配置允许 20～2500 ms |
| 单次修正上限 | 平移分量模长默认 30 mm，界面可在 0.01～30 mm 调整；旋转角默认 10°，配置允许 0.01～10° |
| 平均最近邻残差验收 | 至少改善 5%，且修正后不超过 5.5 mm；全会话统一使用，不自动收紧 |
| 机器人状态最大年龄 | 500 ms |
| 候选结果最大年龄 | 从本次采样派发起 4000 ms |

采样和 ICP 最多只有一个任务在途。繁忙时跳过采样，不排队、不阻塞主 KCF 或机器人通信线程。窗口帧数、窗口年龄、每帧和整窗点数分别有界；所有求解批次均清窗。近共线或覆盖不足的窗口拒绝写回。失败后同样冷却，防止持续重复求解。

配准前后残差计算是 O(N×M)，因此在进入 pipeline 前先限制两侧点数，而不只依赖 PCL 内部抽稀。

## 写回与生命周期

写回只在主视觉和同帧 RobotSim 查询均空闲时提交，暂缓新的同帧查询；相机继续采集，保留最新待处理帧。成功后推进模型代次、清除旧窗口和旧待处理帧，下一份仿真参考从新模型生成。不会像参考工程 IBVS 路径那样发送机器人保持位置指令。

停止、重启、在线阶段切换、Vision 暂停/恢复、RobotSim 重连/切换场景、投影或标定配置变化，以及机器人运行/保持/模式改变都会撤销旧代次。机器人快照过期时清窗，写回读取位姿后再次核对原子代次和快照截止时间。旧任务返回不得重新启用会话或写入新工件。

读取失败立即返回；局部写回的前置读取超过 150 ms 时不再继续发送位姿修正。SET_POSE 已发出但回读失败时，不重复应用同一修正，停用本轮自动工件更新，主纠偏流程继续。需重新开始在线会话才能恢复自动更新。

## 性能观测与限制

运行日志中的 `[在线局部定位]` 记录实际窗口、点数、采集及处理耗时、求解耗时、配准前后残差、拒绝原因和写回耗时。程序启动还输出本次启用状态及频率参数。

2500 ms 是配准流程返回后的验收门槛（包含 ICP 和配准前后残差评估），现有 PCL 没有硬中断接口；不能把它描述成计算一定在 2500 ms 内结束。任务独立于 UI、KCF 和机器人通信，仍会使用 CPU，真实设备上的帧间隔和 CPU 占用需联调测量。

写回仍使用同一个 RobotSim 通道，期间检测叠加刷新会等待位姿事务；它不是保证零抖动的异步网络协议。故障时单次请求仍受 `robotsim_endpoint.txt` 中 `request_timeout_ms` 控制，可能出现约一个请求超时的等待。默认 1000 ms。超时后不连续重试自动工件更新，不能把原始相机继续刷新等同于检测叠加完全不中断。

## 2026-10-22 仿真辅助接缝与母材表面更新

### 用户目标与来源隔离

### 表面辅助更新的启用条件

启动配置新增 `surface_assisted_updates_enabled=true`，对应 `Options::surfaceAssistedUpdatesEnabled`；关闭后恢复原独立焊点验收要求。该选项只作用于正式在线工件局部定位，不影响离线、初始反向扫描、全局定位和普通 IBVS。没有已通过后验并读回的可信工件位姿时，缺焊点路径不能完成第一次工件写回；初始位姿不能只因存在模型或 SET_POSE 回读成功就视为几何已确认。

表面任务使用冻结的相机帧、机器人/外轴姿态、参考对象、工件位姿版本和当前虚拟激光线。原图接缝缺失时，不再因此销毁仍有效的母材表面窗口；真实表面无效、会话/场景/位姿版本变更、参考错帧或机器人状态失效仍撤销任务。工件位姿写回与恢复都会推进位姿版本；SET已发送但回读未确认时也推进版本并保持故障暂停，不能假定场景未变。旧版本的像素补偿、表面窗口和待发结果不可混用。

现有 DigitalTwin DTO 的 `valid` 仍要求至少两个仿真激光图像点及仿真焊缝图像点；首版解除的是对真实焊点的强制依赖，不宣称仿真焊缝参考也可缺失。`seamIndex=-1` 不代表接缝材料身份已确认；当前 RobotSim 服务也未填充 `localPointCloud_mm`，这里使用的是实际返回的虚拟激光扫描线。

配准继续使用现有 PCL 流程，不移植离线实验中表现不足的 NumPy 求解器。`LocalCorrectionRequest` 和 pipeline 请求新增缺省单位阵的 `initialGuess`，方向为真实云到参考云；只有已验证位姿后的表面通道使用训练真实/虚拟云质心差作为平移初值，留出帧不参与。新增的纯Z平移三面夹具表明，原单位初值可能使旧LM返回无改善的单位候选；未通过的参数维度调整已撤回，共享warp参数化保持原状。训练质心差只是求解初始化，不是已验收位姿；裁剪或密度偏差仍可能令候选失效，最终仍在原始训练云、留出云和写后新帧上验收。缺焊点表面支路将完整帧按时序分成训练帧与后部留出帧，不将同帧密集点随机分割冒充独立验证。预焊点中心邻域采用24 px半宽排除掩膜；它只减少局部凸起对整体位姿的影响，不证明所有预焊点和反光均已正确分割。

### 根因位置与最小修改

1. RuntimeLocalRegistration 原先把冻结帧的机器人状态超过 500ms 和当前通信超过 500ms 合并处理。慢图像结果因而撤销已确认写回事务并永久 fault。现在先隔离旧会话/旧 epoch，当前真实失鲜、停止、Hold、模式变化仍优先撤销；只有曝光快照过旧时跳过采样、打断后验连续合格帧，不计为恶化，不撤销 pending，不重启原五秒计时。正常验证或原有保留结案后，经冷却与新曝光继续采样。
2. 正式在线的原图扩大搜索分帧执行，每帧 refiner 总调用数最多 2 次；跨帧只缓存候选提示，每个有效测量仍复验当前原图。旧 KCF 身份可靠时继续使用，经完整候选竞争与递增新帧确认才允许重捕获。初扫保持原搜索入口和几何验收门。
3. Control 用初始校正后的有序路径作为预测基准，仅由已释放、非 estimated 实测更新位置偏差锚；最新机器人状态变化时重新计算 P，不复发缓存增量。相同控制位姿回包不自激生成新命令。停止、报警、阶段退出、reset、段结束等原门禁继续成立。预测沿有序相邻段关联，不按全局最近距离跳到邻近回折支路。
4. UI 消费同一控制目标而非最新相机测量冒充 TCP 目标；旧会话/旧序号不能覆盖新目标，同序号失效快照保留为防重放边界。目标的图像投影不进入纠偏、测量或 ICP。
