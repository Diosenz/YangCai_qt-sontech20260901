# 在线纠偏的工件局部定位

## 行为与边界

在线纠偏进入 `OnlineRunning` 后，独立的 `online-local-registration` 线程从已经完成主视觉处理的同帧上下文采样。复用当前相机图像、冻结的机器人状态和 RobotSim 三维激光线，不增加逐帧仿真请求，不改变机器人 O/P 指令与轨迹 ICP。初始反向扫描、离线纠偏、普通 IBVS 和全局定位不启用本支路。

真实表面线复用现有 Gabor/Steger 全局采线实现，但在独立实例和线程中运行。真实点保留投影器输出的变位机 TCP 坐标，不再加回 `toolTcpInLastLinkMm`；虚拟线必须明确以同一工件父级 TCP 对象 `workpiece_parent_id` 为参考，单位均为 mm。当前场景的参考对象 1063 相对末节已有 Z=231 mm 偏移，不能将其误认为末节原点。调度器核对参考 ID 与父级 ID 一致，场景配置还必须保证该父级的几何定义与投影 TCP 一致。不把间隙检测内部点云或焊缝单点轨迹当作工件表面。

真实/虚拟局部窗口交给现有 `LocalizationLocalCorrectionPipeline`，使用 XYZ 平移及绕 Z 旋转约束。输出的 `virtualToRealCorrectionTransform` 左乘工件当前相对父级位姿，随后 `SET_POSE(relative=true, updateChildren=true)`，再回读世界位姿确认。场景 XML 和工件文件不写入。

## 调度与参数

运行时启动时读取 `config/digital_twin/online_local_registration.ini`。当前值按 2026-10-20 现场日志调整为摆放偏差联调初值，尚不代表经过真实工件的参数标定。

| 项目 | 默认值 |
|---|---|
| 局部图像采样最短间隔 | 200 ms |
| 配准完成后的最短冷却 | 2000 ms，模型写回清窗仍保留冷却 |
| 有效窗口 | 8～16 帧 |
| 每侧送入配准的最大点数 | 512 |
| ICP 最大迭代 | 40 |
| ICP 最大对应点距离 | 默认 10 mm；在线界面可在 0.1～10 mm 调整 |
| 求解后验收耗时预算 | 2500 ms；配置允许 20～2500 ms |
| 单次修正上限 | 平移分量模长默认 30 mm，界面可在 0.01～30 mm 调整；旋转角默认 10°，配置允许 0.01～10° |
| 平均最近邻残差验收 | 至少改善 5%，且修正后不超过 5.5 mm；全会话统一使用，不自动收紧 |
| 机器人状态最大年龄 | 500 ms |
| 候选结果最大年龄 | 从本次采样派发起 4000 ms |

采样和 ICP 最多只有一个任务在途。繁忙时跳过采样，不排队、不阻塞主 KCF 或机器人通信线程。窗口帧数、窗口年龄、每帧和整窗点数分别有界；所有求解批次均清窗。近共线或覆盖不足的窗口拒绝写回。失败后同样冷却，防止持续重复求解。

配准前后残差计算是 O(N×M)，因此在进入 pipeline 前先限制两侧点数，而不只依赖 PCL 内部抽稀。

## 写回与生命周期

写回只在主视觉和同帧 RobotSim 查询均空闲时提交，暂缓新的同帧查询；相机继续采集，保留最新待处理帧。成功后推进模型代次、清除旧窗口和旧待处理帧，下一份仿真参考从新模型生成。不会像参考工程 IBVS 路径那样发送机器人保持位置指令。

停止、重启、在线阶段切换、Vision 暂停/恢复、RobotSim 重连/切换场景、投影或标定配置变化，以及机器人运行/保持/模式改变都会撤销旧代次。机器人快照过期时清窗，写回读取位姿后再次核对原子代次和快照截止时间。旧任务返回不得重新启用会话或写入新工件。

读取失败立即返回；局部写回的前置读取超过 150 ms 时不再继续发送位姿修正。SET_POSE 已发出但回读失败时，不重复应用同一修正，停用本轮自动工件更新，主纠偏流程继续。需重新开始在线会话才能恢复自动更新。

## 性能观测与限制

运行日志中的 `[在线局部定位]` 记录实际窗口、点数、采集及处理耗时、求解耗时、配准前后残差、拒绝原因和写回耗时。程序启动还输出本次启用状态及频率参数。

2500 ms 是配准流程返回后的验收门槛（包含 ICP 和配准前后残差评估），现有 PCL 没有硬中断接口；不能把它描述成计算一定在 2500 ms 内结束。任务独立于 UI、KCF 和机器人通信，仍会使用 CPU，真实设备上的帧间隔和 CPU 占用需联调测量。

写回仍使用同一个 RobotSim 通道，期间检测叠加刷新会等待位姿事务；它不是保证零抖动的异步网络协议。故障时单次请求仍受 `robotsim_endpoint.txt` 中 `request_timeout_ms` 控制，可能出现约一个请求超时的等待。默认 1000 ms。超时后不连续重试自动工件更新，不能把原始相机继续刷新等同于检测叠加完全不中断。

### 写入前独立检查与累计预算

主视觉适配器从同帧 `beforeFusionPoint` 生成独立父级 TCP 焊点，要求主结果有效、响应存在且完成、无相关/融合跳变拒绝、原始像素在图内及投影有效。该点不依赖诊断记录开关，也不使用融合后像素。缺失或无效时撤销旧窗口和候选，包括仍在计算的旧代次结果。KCF 可能误跟踪，独立检查仅提供额外否决依据，不能当作真实位置的精度保证。

局部 worker 对窗口内每帧独立焊点逐一检查：候选后误差不超过 `maximum_independent_error_mm`（默认5.5），且不比修正前恶化超过 `maximum_independent_worsening_mm`（默认0.1）。同时增加修正后双向对应覆盖（默认3 mm内至少70%）、匹配区域两条主方向跨度比（默认至少50%）和匹配区域退化检查。PCA只排除明显近共线，不宣称平面能够唯一约束所有自由度；额外校验输出为有限刚体矩阵。

生产运行在 RobotSim worker 中显式建立安全会话。首次候选写回前读到的工件相对父级位姿作为初始恢复与累计基线，未被称为已通过后验几何验证。默认限制候选工件原点相对此基线偏移30 mm、相对旋转10°，并对当前独立仿真焊点转换得到的材料点检查单步及相对基线位移不超过30 mm。单次平移上限、累计原点位移及旋转造成的材料点位移分别检查；不能仅比较修正矩阵的平移分量。仅有当前可观测焊点，不代表覆盖整件工件所有边角。

### 指令确认、几何验证与恢复

成功 SET_POSE 回读只进入待验证状态，保持写入代次并暂停追加局部修正。仅使用写回完成后曝光的不同新帧，按同帧真实原始焊点与仿真三维焊点检查：当前误差应在独立上限内，且不比将本次修正取逆得到的旧位姿同帧对照恶化超过容差。该对照不是重新渲染旧场景的真值重放；不同场景下仿真激光交点可能变化，因此仍需现场效果复核。

连续3份合格新帧后，worker重新读取场景位姿，确认仍等于本次目标后晋升为已验证位姿，再清窗升代继续。连续3份失效/恶化观测或5秒未能确认时，只在会话、代次、活动机器人状态、场景修订、工件/父级/参考对象以及当前相对位姿仍匹配本次目标的条件下，尝试恢复上次可信位姿并回读。恢复成功后仍暂停本会话自动更新，避免重复错误匹配；恢复结果未知禁止重复恢复。

停止、保持、断连、会话替换及验证期间热调会撤销代次并暂停自动更新，不触发恢复设备操作。已发送指令不能被撤销；若写回过程中发生撤销，保留故障保护，不能将旧结果作为新代次继续追加。外部修改工件位姿时拒绝恢复覆盖；现有协议无法区分“同ID、同位姿但外部替换模型”，仍需操作者通过显式场景重配置维护身份。

### 可重放归档

局部表面链路使用独立目录 `output/online_local_registration/<UTC时间>_session_<id>/`，不混用轨迹ICP的 `online_icp_points.txt`。每次尝试保存逐帧原始双云、独立点、实际输入窗口、SOR后求解云、参数、修正矩阵、最终诊断对应关系、残差/覆盖/拒绝原因。事务侧附保存写入前/目标/累计基线/已验证矩阵及指令结果；后验记录新帧时间和误差证据。诊断对应是最终两向最近邻关系，不是PCL迭代内部全部对应历史。

文件在所属后台线程中以 QSaveFile 提交；归档失败不能接受新写回。默认每会话最多128次尝试，跨清窗、代次变化和热调保持预算，不删除或覆盖既有归档；达到预算后需要新会话。原始单帧点数也有内存上限，超出则拒绝而不伪称完整归档。验证结果及现场限制在本轮完成后补充。
