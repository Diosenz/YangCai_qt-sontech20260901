# MKCF 训练目标与数值约定

2026-10-26。适用于 `Vision/src/track/KcfTracker.cpp` 的 Mkcf 路径；Standard KCF 保留原来的频谱、训练和复数除法语义。本说明记录实现依据，不代表真实设备或现场精度已通过。

## 目标与模板基底

来源是刘涛论文第 3 章式 3-8、3-9、3-15、3-17、3-31，以及已迁移的 FHOG、灰度、Gaussian kernel 和 FFT 实现。三模板分别为本次实拍递推模板、同曝光仿真外观、上一已接纳实拍递推模板；对偶系数 beta1 仅与同次训练的实际递推基底配对检测。

式 3-31 的 `U_i=(1-eta)*U_(i-1)+eta*U_raw` 更新的是实际模板特征。正常接纳后，先按既有学习率生成候选 U_i，以 U_i 重建当前模板的全部核并求 beta1，历史约束仍用 U_(i-1)。成功后才同时提交 U_i、权重、beta1；下一帧再以已提交 U_i 作为历史。拒绝或数值失败不推进模板。不能仅更新历史旁路而每帧 100% 替换实际检测模板，也不能单独混合 alpha 或把 raw 基底的 alpha 与 EMA 特征配对。init 会清空上一生命周期的检测/历史基底。

两个特征核共享非负权重 t=(tH,tG)。设 Kij(t)=tH*KijH+tG*KijG，目标为

```text
J = .5 sum_i ||g-Kii(t) beta_i||²
  + .5 lambda sum_i beta_i* Kii(t) beta_i
  + .5 mu sum_i<j [beta_i* Kii(t) beta_i
                   + beta_j* Kjj(t) beta_j
                   - 2 Re(beta_i* Kij(t) beta_j)]
  + .5 nu (tH+tG-1)²,  tH,tG >= 0.
```

三模板时 mu_paper=2*mu_code；因此 beta 方程的正则为 lambda+2*mu_code，权重线性项为 `.5*(lambda+2*mu_code)*U-mu_code*C`。实现统一推广为 n 个模板的 `(n-1)*mu`。一次优化固定 mu，不沿用每轮乘二的旧原型 continuation。10 次是迭代上限，不宣称达到联合全局最优；权重相对变化小于 1e-5 时可提前停止。

## 空间与频域

FHOG 归一化删除外围一圈 cell，灰度也先裁同一圈，再以相同格距采样并乘 Hann。灰度转换本身已给出 [0,1]，不再次除以 255。

MKCF 保留原采样尺度，仅按既有 FHOG 规则对齐窗口边界。固定 96 像素模板曾将 375 像素搜索宽度压至 104 像素，细条纹不足一像素；生产逐帧 trace 已确认反射出现前即产生反向小位移。Standard/Fused 的固定窗语义保持原样。原采样增加计算量，必须另外验收会话运行耗时。

训练核与标签均以零位移为数组原点。既有相关核先将零位移放在中心，所以 MKCF 训练前将其移回原点。当前模板几何保证偶数特征格。检测仍用中心形式互核，将零位移峰放回图像中心，保留既有坐标换算。

forward DFT 不缩放，inverse DFT 除以 N=height*width。因此 A、b、U、C 的全部频域内积除以 N 后才与 nu 组合；A 的交叉项使用 `Re(conj(km)*kp)`，避免特征格尺寸改变软罚强度。

## 两个子问题

固定 beta 后，令 `c=.5*(lambda+(n-1)*mu)*U-mu*C`。权重目标是

```text
q(t)=.5*t' A t + (c-b)'t + .5*nu*(1't-1)²
H=A+nu*11', r=b-c+nu*1.
```

二维非负 QP 比较原点、两条轴最小值与非负内部解，按同一目标选最小值。不截负无约束解、不硬归一化，也不在优化循环中用帧间 EMA 混合权重。H 明显不定或输入非有限时，本次模型不提交；不加任意 jitter。

固定 t 后，每个频点直接解原始驻点系统：

```text
[kii²+(lambda+(n-1)*mu)*kii] beta_i
  - mu sum_j!=i kij beta_j = kii*g.
```

实现优先对最多三个未知数的双精度复数系统做带列主元消元；病态、秩亏或后向残差不合格时，回退最多 6x6 实数等价系统的 SVD 最小范数解。方程、秩判据的量纲和验收残差保持一致，不先除以 kii，也不使用给分母平方幅值无条件加 epsilon 的复数除法。求解检查归一化后向残差不超过 1e-8，转换为 float 后再次检查有限性。每次权重更新后重新求 alpha，最后提交的权重、alpha、当前模板属于同一模型。小系统快速路径只减少逐频点 SVD 开销，不能以恢复固定低分辨率窗口来换取速度。

## 可独立复核的反例与验证边界

- H=[[2,1],[1,2]]，r=(-1,2)：非负最优为 (0,1)，原目标值 -1；截负无约束解得到 (0,5/3)，目标值 -5/9。
- A=I、b=(2,1)、c=0、nu=1：软解为 (4/3,1/3)，和为 5/3。旧测试要求权重和为一与该目标冲突，已移除该内部断言；公开跟踪行为仍须通过会话回归。
- 标量空间 A=1、b=2、c=0、nu=1：软解 1.5。N=8 的频域内积若漏除 N，会错误得到 17/9。
- 小分母真实商不能被无条件 epsilon 缩小；原始驻点系统与最终权重重解避免该偏置和新权重/旧 alpha 的配对错误。

上述代数检查不能替代生产会话测试。必须保留正常可见焊缝、竞争条纹和完整 runtime → 投影 → 控制队列 → 模拟通信结果；不能因矩阵求解正确就宣称目标身份、预焊恢复或现场 2/5 mm 精度通过。

初始化前复用已有实拍身份有效性检查，空白图不能仅凭有效仿真提案建立实拍模型。否则第一张黑图会留下空白身份，后续清晰图只能在错误锚附近等待重捕获；拒绝初始化时保持未初始化，下一新曝光仍可正常首捕。这不比较虚实灰度相似度，也不恢复已移除的仿真准入条件。

正常 PSR 分布按响应实际使用的模板数量分别积累；可信焊前单模板和三模板响应不混合统计。至少30次对应模型的可信焊前响应才启用双侧3σ，正式在线不补收异常实拍作为正常样本。统计不足时仍以完整当前图像证据判断实拍训练，不因数量不足取消图像输出。实拍训练 ROI、身份块和融合前输出观测使用同一取样锚；异常或部分遮挡时复用仿真替代训练，不污染可信实拍模板。
