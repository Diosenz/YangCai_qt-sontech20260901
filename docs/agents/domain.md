# 领域文档

本仓库采用 single-context 布局：

- 根目录 `GLOSSARY.md`：领域术语。
- `docs/adr/`：架构决策记录。

## 阅读规则

探索代码前，若存在 `GLOSSARY.md`，先阅读相关术语；
若存在 `docs/adr/`，阅读与当前任务相关的决策。

文件不存在时继续工作，不为完成初始化创建空文件。
在实际澄清术语或形成架构决策时，再按任务需要建立文档。

## 使用规则

- 使用术语表已有的领域名称，保持概念含义一致。
- 方案与既有 ADR 冲突时，明确指出冲突及重新讨论的理由。
- 领域文档与根目录、模块 AGENTS.md 配合使用；
  指令优先级沿用仓库现有约定。
