# 新工程重构交接文档

日期：2026-07-03

## 1. 快速上手

本项目的当前目标是将旧 MFC 工程中围绕 `CRobotleadingDlg` 的机器人视觉、系统标定、离线纠偏、在线纠偏、示教轨迹保存、RobotSim 仿真参考等功能，迁移为独立的 Qt Widgets + CMake 新工程。

当前现场状态：

- 系统标定采集已经在实际设备上人工测试通过。
- 保存示教轨迹已经在实际设备上人工测试通过。
- 在线纠偏可以成功调起机器人 JBI 程序。
- 离线纠偏可以成功调起机器人 JBI 程序。
- RobotSim/DigitalTwin 仿真 observation 尚未接入，在线/离线纠偏完整闭环暂时无法测试。

接手后建议先完成以下动作：

1. 使用 `qt-debug` 或 `qt-release` 配置构建主程序。
2. 先确认程序能启动、图像能显示、机器人能收到有效 D 回包。
3. 接真实设备时按顺序验证：

   ```text
   相机显示
   -> 机器人 N/D 状态轮询
   -> 激光指令 N 字符串
   -> 系统标定采集
   -> 保存示教轨迹
   -> 离线纠偏
   -> 在线纠偏
   -> RobotSim/DigitalTwin 仿真 observation
   ```

## 2. 工程目录与模块职责

新工程只在当前仓库根目录下开发。旧 MFC 工程只读参考，不修改、不格式化、不移动。

当前主要生产模块：

| 模块 | 职责 | 注意事项 |
| --- | --- | --- |
| `UI/` | Qt Widgets 界面、运行时编排、worker adapter、配置入口、现场提示 | UI 不直接做重算法、阻塞相机采集或阻塞机器人通信。 |
| `Camera/` | 相机抽象、离线图片设备、Allied/Vimba X 和 Basler/Pylon 适配器 | 真实相机 SDK 通过 CMake option 接入。 |
| `Vision/` | OpenCV 焊缝视觉算法、KCF/Gabor、gap、图像点到空间、ICP 相关视觉工具 | 不依赖 UI，不直接访问 RobotSim transport。 |
| `Control/` | 在线/离线纠偏控制器、标定采集控制器、示教轨迹记录器、状态机和纠偏算法 | 只产生命令 DTO，不直接操作 socket。 |
| `RobotComm/` | 旧 N/O/P/C/J 协议编码、D 回包解析、transport、诊断 DTO | 真实发送边界集中在此模块。 |
| `DigitalTwin/` | RobotSim facade、虚拟参考请求、仿真结果 DTO 与转换 | RobotSim 通信只允许在此模块内。 |
| `Localization/` | 全局/局部定位算法边界、PCL 相关能力 | 公共接口不暴露 PCL 类型。 |
| `IBVS/` | IBVS 起始点、视觉伺服相关算法与配置 | 当前仍需现场流程继续接入。 |

线程边界集中在 `UI/src/RuntimeCoordinator.cpp` 和 `UI/src/RuntimeWorkerAdapters.cpp`：

- Camera worker：相机采集、曝光设置；
- Vision worker：KCF/Gabor/gap 检测；
- RobotComm worker：机器人连接、N/D 轮询、命令事务；
- Online/Offline correction worker：纠偏状态机；
- Teach trajectory worker：示教轨迹记录；
- UI thread：只做 QWidget 更新和用户交互。

原则：所有 QWidget 更新只能在 UI 线程；跨线程传递使用 Qt queued signal/slot 或按值 DTO。

## 4. 配置和数据路径

### 4.1 标定文件

默认标定文件：

```text
config/calibration/SENSORPARA.txt
config/calibration/RBCALIB.DAT
```

用途：

- `SENSORPARA.txt`：相机内参、激光平面、相机到工具坐标变换；
- `RBCALIB.DAT`：变位机/机器人标定，解析 `////SRANG`，用于站点坐标与机器人坐标转换。

在线纠偏、离线纠偏和图像点到空间投影均依赖这两份配置。缺失或无效时应禁止启动在线/离线纠偏流程。

### 4.2 工件选择配置

工件下拉框配置：

```text
config/workpieces/workpiece_selection.txt
```

当前格式：

```text
id|界面显示名|weldment模型路径|全局定位JBI|在线纠偏JBI(InitType)|在线纠偏JBI(GlobalCorrection)|在线纠偏JBI(IBVSStart)|离线纠偏扫描JBI|在线纠偏示教轨迹基名|离线纠偏示教轨迹基名
```

注意：

- 在线纠偏和离线纠偏的 `_W/_T` 文件可以不是同一套；
- 配置文件只写基名，不写 `_W.txt` 或 `_T.txt`；
- 程序读取：

  ```text
  data/WorkPiece/<在线纠偏示教轨迹基名>_W.txt
  data/WorkPiece/<在线纠偏示教轨迹基名>_T.txt
  data/WorkPiece/<离线纠偏示教轨迹基名>_W.txt
  data/WorkPiece/<离线纠偏示教轨迹基名>_T.txt
  ```

- 三个在线纠偏 JBI 分别对应 UI 的起始点方式：
  - `InitType`
  - `GlobalCorrection`
  - `IBVSStart`

### 4.3 示教轨迹和 replay 数据

示教轨迹目录：

```text
data/WorkPiece/
```

保存示教轨迹临时目录：

```text
data/trajectory_capture/
```

典型 replay 数据：

```text
data/replay/penzui/
data/replay/chufengkoufan/
data/replay/zhixian/
```

这些目录中常见文件：

```text
SENSORPARA.txt
RBCALIB.DAT
robotPos.txt
simulatedLaser.txt
simulatedWeldpt.txt
*_W.txt
*_T.txt
```

### 4.4 RobotSim 配置

RobotSim 端点配置：

```text
config/digital_twin/robotsim_endpoint.txt
```

当前文件说明：RobotSim ZeroMQ 服务端口由 RobotSim 控制台打印，需要将端口填入配置或 UI 输入框。

```text
host=127.0.0.1
port=0
connect_timeout_ms=1000
request_timeout_ms=1000
```

`port=0` 表示尚未配置有效端口。

现场需确认：

- 真实相机画面中的焊缝点是否落在仿真 observation 提供的 ROI 附近；

现场需确认：

- RobotSim 是否提供稳定的二维激光线；
- RobotSim 是否提供焊缝点二维坐标；
- RobotSim 当前未提供 `seamIndex` 和 `scanLineChangePoint` 时，在线分段 ICP 是否需要 callbacks 或后续协议扩展；
- `frameId` 是否能和相机帧严格绑定。

## 7. 仿真 / DigitalTwin 接入说明

### 7.1 当前推荐入口

Vision 当前优先消费：

```text
DigitalTwinVisionLaserObservation
```

定义位置：

```text
DigitalTwin/include/DigitalTwinVisionTypes.h
```

Runtime 发布入口：

```text
CRuntimeCoordinator::publishDigitalTwinVisionObservation(...)
```

Vision worker 接收入口：

```text
CVisionTrackingWorkerAdapter::updateDigitalTwinVisionObservation(...)
```

处理原则：

- DigitalTwin observation 有效时优先使用；
- `frameId` 相同则按同帧使用；
- 无法严格匹配时使用最新有效 observation，并在 message 中标记 fallback；
- 无有效 DigitalTwin observation 时走旧 callbacks；
- callbacks 也无效时返回 `simulated observation unavailable`；
- `startTracking()` 和 `stopTracking()` 清空缓存，避免旧数据串入下一轮。

### 7.2 Observation 最小有效条件

DigitalTwin 转 Vision observation 成功要求：

```text
reference.available == true
laserLineImagePoints_px.size() >= 2
hasSeamPointImage_px == true
```

当前 RobotSim 未提供时保持默认：

```text
seamIndex = -1
scanLineChangePoint_mm = std::nullopt
```

不要在主工程侧伪造 seamIndex 或 scanLineChangePoint。若在线两段 ICP 必须依赖切换点，应由 RobotSim 协议扩展或 callbacks 明确提供。

### 7.3 旧 callbacks 兼容路径

保留的旧函数名和顺序：

```text
toNextWeldSeam()
-> generate_simu_laser1()
-> getSeamPoint2d()
-> getCurrentVirtualLine()
-> getSeamIndex()
-> getScanLineChangePoint()
```

用途：

- 离线 replay；
- 手动接入旧 VirtualLaserSensor；
- RobotSim 未完全提供实时 observation 前的临时兼容。

注意：

- KCF/Gabor/gap 使用同一条仿真激光线；
- 仿真激光线必须是整图 pixel 坐标，不是 ROI 局部坐标；
- 焊缝点必须和仿真激光线同帧、同坐标系；
- 仿真线附近应有足够连续点，否则 Gabor 方向估计不稳定。

## 8. 常见问题排查

### 8.1 程序启动后无实时图像

检查：

- 是否启用 Allied 构建 option；
- Vimba X SDK 是否安装；
- 运行目录 PATH 是否包含 Vimba X DLL；
- 相机是否被其他软件占用；
- `AlliedCameraDevice::stateText()` 日志；
- `Camera/vendor/CommCamera/src/CameraAllied.cpp` 连续采集状态。

### 8.2 Device 显示未连接

Device 应按有效 D 回包判断，不只按 socket 判断。

检查：

- 控制柜 IP/端口；
- transport 是否连接成功；
- N 请求是否发出；
- D 回包是否完整；
- `RobotProtocolCodec::decodeRobotState(...)` 是否解析成功；
- 日志中的最新 N/D 原文和错误文本。

### 8.3 点击激光指令后硬件无变化

检查：

- 最新 N 请求中 `s_laser` 是否变为 1/0；
- 控制柜是否实际消费 `s_laser` 字段；
- 激光器是否由控制柜统一控制；
- 是否存在独立传感器 SDK/IO 未接入。

当前实现不直接调用传感器 SDK 开关激光。

### 8.4 KCF 检测失败或漂移

检查：

- observation 是否有效；
- `weldPointImage_px` 是否在图像范围内；
- `laserLineImagePoints_px` 是否至少 2 点；
- 仿真线是否覆盖 `250x200` ROI；
- 真实图像中对应位置是否有激光条纹；
- 相机帧与 RobotState / RobotSim observation 是否同步；
- replay 数据是否与当前帧号对应。

### 8.5 O 点坐标不正确

检查：

- `_W/_T` 是否为变位机坐标，单位 mm；
- 每个 T 点是否有对应 `s1/s2`；
- `RBCALIB.DAT` 是否来自当前设备；
- `stationPoseToRobotPose()` 是否返回有效；
- O 协议单位是否为位置 um、姿态 deg*10000；
- 控制柜收到的 O 字符串字段顺序是否与旧协议一致。

### 8.6 离线纠偏不自动结束

检查：

- Offline worker 是否处于 WaitingForDetection 或 Detecting；
- RobotState 中 `detflag` 是否变为 2 或 3；
- `detflag` 是否曾经回到 0；
- 是否因锁存防重复触发；
- Vision tracking 是否已启动并累计有效点。

### 8.7 保存示教轨迹没有点数

检查：

- D 回包中 `s_Bsavetraj` 是否为 1；
- 机器人位姿是否变化；
- 距离变化是否超过 `_W` 记录阈值；
- 临时文件目录是否可写；
- UI 是否显示最新 recorder snapshot。
