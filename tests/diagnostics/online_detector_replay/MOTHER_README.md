# 原图母材部分约束（任务05）

使用已存在完整 `process` 图像分支回放和 `--evidence`，显式配置
`enable_mother_constraints=true` 后，独立 OpenCV 观察器读取生产入口输出的原始灰度 PNG。
它不读取 `scene`、真值点、遮挡标签或 manifest 自填的母材线。
默认关闭，可与原基线比较；生产 Vision/Control 未修改。

```sh
python3 tests/diagnostics/online_detector_replay/test_mother_constraints.py
python3 tests/diagnostics/online_detector_replay/make_mother_demo.py --output output/analysis/mother_demo_run1
```

## 支撑与可观测性

- 初始候选由生产最终验收几何提供。观察器在候选中心之外扫描真实灰度列，
  验收窄亮带、竞争峰比例、支撑数量/跨度、拟合残差和左右分支方向。
- 只有经过业务确认的独立几何能更新历史分支方向、目标到分支的法向偏置。
  后续搜索中心随可靠锚/已对齐参考相对预测移动，方向沿历史母材线，
  不是固定在合成图某条横带。当前覆盖与原生产相同的 V 型双分支图像家族，
  不能直接推广为所有焊缝方向或任意曲面。
- 中心外拟合与中心像素的一致性不够时，生产即使报告 Geometry，
  也不能更新业务可靠锚。附加折点/弧顶可能被当作干扰，此处**不做预焊类别识别**。
- 两个足够独立的侧面法向可提供二维外推估计；单侧仅沿法向修正预测，
  其切向分量仍是预测。弱法向组合降为一维，不能当完整观测。
- 目标到母材线的历史偏置是模型假设；双侧中心外推也不是直接看到了被遮住的接缝。
  任意亮线符合历史斜率仍不能证明母材身份；长期遮挡、形变和反光需继续降级/不可用。
- 部分约束仅在任务04原预算与参考/计量条件都合格时提供像素估计。
  不改变参考映射、锚点、年龄或行程预算；超预算即不可用。
  无侧支撑时保留有界预测；无锚、未知进度/时间、参考未对齐时不给辅助点。

## 数据与门限

`mother_options` 是显式候选配置对象。完整有效值随每帧 `mother_observation.options`
导出，未知键或非法范围非零失败。主要参数包括搜索跨度、中心排除宽度、历史搜索带宽、
初扫高度、最少支撑列/跨度、对比度、最大亮带宽度、拟合 RMS、方向变化、竞争比例、
法向行列式、最大修正、中心支撑比例及几何候选与外推的一致性。
这些默认值只用于离线原型，未现场标定；不是普适的焊缝或预焊点判定阈值。

`mother_observation` 导出：实际支撑像素、拟合斜率/截距、法向与目标约束 RHS、
跨度/残差/竞争与宽峰拒绝、中心一致比例、约束秩、预测提案与估计结果、
历史分支假设、原图 PNG 哈希和 C++/Python 实现哈希。
`learned_model` 是当前可供观察的候选模型，只有业务独立几何确认时才保存为历史，
不能把该字段存在解释为锚点/模型已刷新。

无历史偏置时，几何候选用于初始化偏置，仅在实际两侧和中心像素均通过时建立业务锚，
不把无锚侧线交点变成真实焊点。母材估计统一为 `source=mother_material_estimate`，
`can_independent_validate=false`、`positioner_tcp_mm=null`、
`space_available=false`、`control_eligible=false`。

## 演示与限制

演示包括正常中心、弧顶遮挡双侧、单侧、全丢失、弱法向、生产仍接纳的小附加折点、
预算到限，以及真实稀疏图。`mother_viewer.html` 绘制当前实际支撑像素与拟合线，
同时显示生产原始候选、预测提案和业务 KCF。
合成真值只存在独立评估器，误差/可用率含首次确认期间不可用帧，分母明确。

真实归档 14591、15248 缺连续曝光时间和沿缝计量，使用声明为非实际曝光的诊断投影上下文。
观察器没有强制取得有效母材支撑；不满足条件就拒绝，不把这两张稀疏图当现场连续预焊验证，
也不以其三维坐标宣称精度。真实/合成结果分开保存。

原生产 KCF 可能已在当前 `process` 内训练；离线母材门禁只能拒绝业务资格，
不能撤销它的私有训练。实际训练事实完整保留于 `raw_detector`，后续训练事务策略另行实现。
辅助约束不能覆盖重捕获过渡输出；新的业务锚需母材门禁和恢复身份门禁都通过。
不安装依赖，不运行设备，不替代 Windows/VS2022/OpenCV3.4.x 验证。
