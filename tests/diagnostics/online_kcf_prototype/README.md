# KCF 点证据离线原型（非生产）

问题：遮挡、母材可见、反光竞争和参考变化期间，输出依据及可信边界是否清楚，
是否会把错误续接当作可靠实测？同时暴露预测与恢复的实际像素误差。

直接双击 `output/analysis/online_kcf_prototype_20261024/prototype.html`。
页面单文件，图像与数据内嵌，选择场景、逐帧移动或改变预算即可查看。

重新生成需要已有 Python NumPy/Pillow 与 Node.js，不安装依赖，不连接设备。
在已有依赖的 Python 环境中调用：

```sh
python3 tests/diagnostics/online_kcf_prototype/build_demo.py output/analysis/online_correction_repro_20261024/RefinerReplay-e746139ecf871cc4
```

最后一个参数是已有诊断二进制，仅用于运行固定版本的原始单帧精定位代码。
二进制的生成、源文件哈希及生产版本固定方式见相邻 `online_correction_repro/`。
可以省略参数只生成方案演示，但那次回放不包含合成帧的生产基线。
`inputs.json` 保存原图提取证据、合成真值及基线结果；`replay.json` 保存与页面
相同纯函数产生的逐帧输出；`summary.json` 同时记录可用帧数和可用帧误差。

## 范围与限制

- 共九个合成序列、220 帧。图像由独立公式生成；提取器只读取像素，状态函数
  不读取合成真值。固定搜索带、亮度阈值、斜率和中心可见性检查仅适合这些
  简化场景，不能作为新的现场检测算法或“已解决预焊点”证据。
- 保留现有精定位作为对照；不是完整在线检测器回放，没有复现 KCF 模板更新、
  曝光投影、控制轨迹 ICP、P 指令或设备运动。外观相似度续接未实现。
- 九个序列只是覆盖证据流程，不代表真实反光、预焊点体积及遮挡的完整分布。
- 真实帧 10653、14591 仅展示原始生产代码结果，没有焊缝真值，不运行合成
  专用提取器。帧 10653 仍被生产精定位拒绝，问题没有在生产中修复。
- 0.9 秒、2 mm、3 帧确认、2 px 过渡、8 px 身份门限都是演示候选值。
  沿缝距离使用合成输入，不从机器人 TCP 净位移计算。无实际 mm 精度保证。
- 参考版本跳变采用保持旧参考连续的简化重对齐，不能识别全部真实运动与
  位姿修正；远距离重捕获、平行母材、参考长期失效仍需进一步设计。
- 误差图包含恢复过渡。预测偏离真值时，来源标注和时间预算不会消除偏差；
  没有误差上界就不能仅凭“仍在预算内”认定适合 TCP 继续执行。
- 真实准确性需独立焊缝真值，按同一沿缝位置比较，分开评价图像、投影、
  控制参考改变量与 TCP 跟踪；TCP 不能作为焊缝真值。

本原型依用户授权保留为本地诊断材料，未创建提交或推送，也未修改生产模块。
