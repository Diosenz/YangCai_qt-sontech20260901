**What to build:** 在控制离线回放中，经过验收的实测 KCF 轨迹成为跟随参考的主要依据；模型只辅助，不默认以拟合模型点替换实测，处理造成的几何变化可以直接检查。

**Blocked by:** [03｜可靠实测优先，仿真缺失不拦截](03-measured-kcf-priority.md)

## Acceptance criteria

- [x] 在同一明确工件坐标内保留原始实测点、处理后的释放点和最终局部跟随参考，并关联观测来源。
- [ ] 与当前模型替换路径对照回放，验证新的参考以验收通过的实测轨迹为主；不只是修改 UI 显示。
- [x] 明确并参数化平滑、重采样及模型约束的允许改变量，实测与模型冲突时保留证据，不静默覆盖；未定现场阈值不得假定已经达标。
- [x] 不同采样密度不逐行硬相减；折线最近距离仅作为诊断，不能冒充同沿缝位置真实误差。
- [x] 估计点不能通过改名或有效位取得实测控制资格；其执行、减速、停止策略留在独立待定范围。
- [x] 复用坐标契约验证曝光投影、外轴变换和偏移只应用一次；不将变换矩阵平移模当作视觉点改变量。
- [x] 离线输出跟随参考和预期纠偏结果，不发送真实运动命令。

## Execution boundary

本任务发布不扩大生产修改或设备运动授权。当前可执行分析、独立离线实现与回放；
涉及生产 Vision、Control 或其他模块变更时，先落实规格中的协作边界及相应授权。
不得修改只读旧工程和 RobotSim，不新增无关依赖，不删除文件。
门限可作为显式离线候选参数验证，不将未标定值声明为现场精度或执行保证。
