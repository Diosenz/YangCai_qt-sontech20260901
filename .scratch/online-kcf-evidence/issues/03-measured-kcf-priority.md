# 03: 可靠实测优先，仿真缺失不拦截

Category: enhancement
Status: ready-for-agent
Resolution: completed
Updated: 2026-10-24

## Parent

[01｜实测 KCF 为主的在线焊缝检测与轨迹续接规格](01-measured-kcf-spec.md)；需求正文见[正式规格](../spec.md)。

**What to build:** 同一可见母材接缝在仿真参考存在或缺失时，都能依据有效原图几何产生实测 KCF 点；操作人员能看到可靠锚点何时建立、为何刷新，并保留原始测量供精度检查。

**Blocked by:** [02｜建立可追溯的完整检测回放](02-traceable-detector-replay.md)

## Acceptance criteria

- [x] 优先采用原图中明确可见、几何校核通过且目标身份成立的焊缝位置；不将任意激光折点直接认作目标。
- [x] 用相同原图分别回放仿真有效和缺失情形：仿真缺失本身不能否决独立有效测量；必要标定及曝光姿态无效时仍应报告空间投影不可用。
- [x] 明确并参数化可靠锚点的建立与刷新条件，演示无锚启动、正常更新和不可靠观测被拒绝。
- [x] 保留原始像素测量与最终输出；相似度、纯预测和恢复过渡不能被标为独立几何实测。
- [x] 正常可见场景与现有基线对比，报告原始位置变化和可用性，不能为增加通过率一概放宽歧义门限。
- [x] 真实图像没有独立焊缝真值时，只报告测量结果与一致性，不宣称现场准确率或毫米精度。

## Execution boundary

本任务发布不扩大生产修改或设备运动授权。当前可执行分析、独立离线实现与回放；
涉及生产 Vision、Control 或其他模块变更时，先落实规格中的协作边界及相应授权。
不得修改只读旧工程和 RobotSim，不新增无关依赖，不删除文件。
门限可作为显式离线候选参数验证，不将未标定值声明为现场精度或执行保证。
