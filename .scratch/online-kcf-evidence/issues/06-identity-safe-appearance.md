## Parent

[01｜实测 KCF 为主的在线焊缝检测与轨迹续接规格](01-measured-kcf-spec.md)；需求正文见[正式规格](../spec.md)。

**What to build:** 出现更亮反光、多个合理折点或高相关外观时，系统仍保持原目标焊缝身份；外观仅支持有限续跟，身份无法确认时不强行切换。

**Blocked by:** [04｜失测期间有限续接，参考更新不拖点](04-bounded-continuation.md)

## Acceptance criteria

- [x] 综合历史可靠轨迹、可见母材与可用参考方向验收候选，不只使用亮度、相关分数或距 CAD 最近原则。
- [x] 演示更亮错误候选、高相似错误候选及多个合理候选；不能因分数较高直接切换目标。
- [x] 外观支持的输出单独标明跟踪来源，不能获得独立几何资格，也不能刷新可靠锚点和失测预算。
- [x] 身份冲突时进入既有有限预测或不可用路径，明确拒绝原因；不借助错误候选无限续期。
- [x] 明确模板更新资格与时机，并以退化序列验证错误候选及预测不会污染后续身份判断；待定策略须在本任务中形成可审阅设计。
- [x] 正常目标运动与干扰出现分别可回放，报告误切换、不可用区间及已知真值下的位置误差。

## Execution boundary

本任务发布不扩大生产修改或设备运动授权。当前可执行分析、独立离线实现与回放；
涉及生产 Vision、Control 或其他模块变更时，先落实规格中的协作边界及相应授权。
不得修改只读旧工程和 RobotSim，不新增无关依赖，不删除文件。
门限可作为显式离线候选参数验证，不将未标定值声明为现场精度或执行保证。
