## Parent

[01｜实测 KCF 为主的在线焊缝检测与轨迹续接规格](01-measured-kcf-spec.md)；需求正文见[正式规格](../spec.md)。

**What to build:** 失测后重新出现接缝时，系统先用连续新曝光确认同一目标，再恢复输出；原始实测和恢复过渡分别可见，避免单帧误捕获及平滑掩盖偏差。

**Blocked by:** [04｜失测期间有限续接，参考更新不拖点](04-bounded-continuation.md)

## Acceptance criteria

- [x] 连续新曝光确认目标身份；重复曝光不增加确认计数，不伪造新证据。
- [x] 确认帧数、身份冲突处理和过渡限幅参数化，演示确认中断与重新开始。
- [x] 原始几何测量与过渡输出分别保留，过渡输出仍标为估计，不能凭过渡位置刷新可靠锚点。
- [x] 明确确认后的原始观测何时具备锚点更新资格，且不能以预测或过渡结果自我确认。
- [x] 演示小偏差恢复、较大偏差恢复以及超出身份门限情形；定义无法自动重捕获时的结果，不静默吸附远处候选。
- [x] 同时报告恢复等待区间、原始测量误差与过渡误差，不以平滑代替准确。

## Execution boundary

本任务发布不扩大生产修改或设备运动授权。当前可执行分析、独立离线实现与回放；
涉及生产 Vision、Control 或其他模块变更时，先落实规格中的协作边界及相应授权。
不得修改只读旧工程和 RobotSim，不新增无关依赖，不删除文件。
门限可作为显式离线候选参数验证，不将未标定值声明为现场精度或执行保证。
