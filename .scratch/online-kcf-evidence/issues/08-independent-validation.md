# 08: 隔离独立焊点校验资格

Category: enhancement
Status: ready-for-agent
Updated: 2026-10-24

## Parent

[01｜实测 KCF 为主的在线焊缝检测与轨迹续接规格](01-measured-kcf-spec.md)；需求正文见[正式规格](../spec.md)。

**What to build:** 在定位验证回放中，只有独立原图几何确认的焊缝点能承担独立焊点校验；模型辅助估计不能用于循环自证，同时保留有效的母材表面定位路径。

**Blocked by:** [04｜失测期间有限续接，参考更新不拖点](04-bounded-continuation.md)

## Acceptance criteria

- [ ] 按证据来源授予独立焊点校验资格，不依据统一的 KCF 点名称、输出有效位或相关分数简单授予。
- [ ] 通过相同几何位置、不同证据来源的回放，验证相似度续跟、母材辅助估计、纯预测及恢复过渡不参与独立焊点自证。
- [ ] 可靠原图实测在其几何及空间条件成立时仍可参与校验，保留纳入/排除原因与观测关联。
- [ ] 母材表面 ICP 保留自身独立证据与验收规则，不因缺少合格焊点而被本任务一概停用。
- [ ] 覆盖几何残差改善但覆盖率等后验条件不满足的归档情形，不将后验未通过直接解释为几何一定变差。
- [ ] 记录不同证据对验收结论的实际影响，未运行定位验证入口时不只凭类型标签宣称行为已经改变。

## Execution boundary

本任务发布不扩大生产修改或设备运动授权。当前可执行分析、独立离线实现与回放；
涉及生产 Vision、Control 或其他模块变更时，先落实规格中的协作边界及相应授权。
不得修改只读旧工程和 RobotSim，不新增无关依赖，不删除文件。
门限可作为显式离线候选参数验证，不将未标定值声明为现场精度或执行保证。
