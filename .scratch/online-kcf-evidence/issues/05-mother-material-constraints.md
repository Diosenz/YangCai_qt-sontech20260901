# 05: 预焊遮挡与单侧母材约束

Category: enhancement
Status: ready-for-agent
Resolution: completed
Updated: 2026-10-24

## Parent

[01｜实测 KCF 为主的在线焊缝检测与轨迹续接规格](01-measured-kcf-spec.md)；需求正文见[正式规格](../spec.md)。

**What to build:** 遇到预焊凸起导致的中心遮挡、激光弧线或附加折点时，输出继续指向原母材接缝；可见母材只提供其实际支持的约束，不能将外推位置当作完整实测。

**Blocked by:** [04｜失测期间有限续接，参考更新不拖点](04-bounded-continuation.md)

## Acceptance criteria

- [x] 从原图提取可见母材支持，而非读取合成真值、预设遮挡标签或直接选择凸起中心。
- [x] 分别演示中心可见、中心被凸起遮挡但双侧母材可见、仅单侧可见及支持全部丢失。
- [x] 单侧条纹只约束可观测方向，保留其余分量的预测属性；近乎平行等弱约束明确降级。
- [x] 母材外推位置标为辅助估计，不刷新可靠锚点或预测预算；共用既有失效规则。
- [x] 输出候选、所用母材支持、最终位置及选择/拒绝原因，能解释为何不跟随附加折点。
- [x] 合成场景报告误差与可用率；真实单帧只验证可观察证据，不据此声称连续预焊遮挡已经现场验证。

## Execution boundary

本任务发布不扩大生产修改或设备运动授权。当前可执行分析、独立离线实现与回放；
涉及生产 Vision、Control 或其他模块变更时，先落实规格中的协作边界及相应授权。
不得修改只读旧工程和 RobotSim，不新增无关依赖，不删除文件。
门限可作为显式离线候选参数验证，不将未标定值声明为现场精度或执行保证。
