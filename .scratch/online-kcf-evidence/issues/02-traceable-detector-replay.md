# 02: 建立可追溯的完整检测回放

Category: enhancement
Status: ready-for-agent
Resolution: completed
Updated: 2026-10-24

## Parent

[01｜实测 KCF 为主的在线焊缝检测与轨迹续接规格](01-measured-kcf-spec.md)；需求正文见[正式规格](../spec.md)。

**What to build:** 调试人员能够从真实归档或明确标注的合成序列，经现有在线观测处理入口，逐帧查看最终 KCF 点的依据；同一曝光的输入、候选、输出和参考版本可以关联，并作为后续任务共用的验收入口。

**Blocked by:** None (can start immediately)

## Acceptance criteria

- [x] 确认实施时工作树、审计快照与回放数据的版本，报告差异；不将旧工作树默认为最新生产版本。
- [x] 优先复用现有完整检测入口及运行记录能力；必要的最小适配与回放一并交付，不先开展无关重构。
- [x] 输出最终位置、原始测量、来源、可信状态、可用性及拒绝原因，并能关联曝光身份、时间和参考版本；旧归档缺失字段明确标为未知，不猜造关联。
- [x] 可演示至少一个正常可见场景和一个退化场景；真实图像与合成图像明确区分。
- [x] 完整检测回放与已有单帧精定位回放明确区分；未运行完整入口时不得将单帧结果作为其替代。
- [x] 保留当前行为基线，检查外部可见结果而非内部调用次序；同输入和配置可重复回放。
- [x] 提供可直接复现的入口、所用版本、数据标识及可阅读的结果展示，不连接运动设备。

## Execution boundary

本任务发布不扩大生产修改或设备运动授权。当前可执行分析、独立离线实现与回放；
涉及生产 Vision、Control 或其他模块变更时，先落实规格中的协作边界及相应授权。
不得修改只读旧工程和 RobotSim，不新增无关依赖，不删除文件。
门限可作为显式离线候选参数验证，不将未标定值声明为现场精度或执行保证。
