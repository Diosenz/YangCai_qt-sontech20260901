# 04: 失测期间有限续接，参考更新不拖点

Category: enhancement
Status: ready-for-agent
Updated: 2026-10-24

## Parent

[01｜实测 KCF 为主的在线焊缝检测与轨迹续接规格](01-measured-kcf-spec.md)；需求正文见[正式规格](../spec.md)。

**What to build:** 目标暂时不可见时，依据可靠锚点与参考相对运动输出明确标注的有限预测；超出时间或沿缝行程预算即不可用，模型更新不能把目标拖走或为预测续期。

**Blocked by:** [03｜可靠实测优先，仿真缺失不拦截](03-measured-kcf-priority.md)

## Acceptance criteria

- [ ] 从遮挡前可靠检测锚点续接；无可靠锚时不能仅靠 CAD 绝对交点建立可靠输出。
- [ ] 时间与沿缝行程分别累计，并各自独立触发预测失效；演示不同速度和外轴参与运动的情况。
- [ ] 沿缝行程采用明确的工件相对运动/沿缝计量，不能用 TCP 净位移或固定配置速度直接替代；计量条件不足须标明并处理。
- [ ] 预测、辅助估计与参考更新均不能刷新可靠锚点或重置失测预算。
- [ ] 参考版本/位姿突变保留真实锚点，不把绝对模型跳变直接加入输出；重对齐失败与参考丢失均有明确降级或不可用结果。
- [ ] 所有预算与门限明确为可配置的候选值，未标定值不声明为生产精度保证。
- [ ] 回放预算内仍有位置偏差的反例，输出误差诊断，不把预算未超限等同于适合 TCP 执行。

## Execution boundary

本任务发布不扩大生产修改或设备运动授权。当前可执行分析、独立离线实现与回放；
涉及生产 Vision、Control 或其他模块变更时，先落实规格中的协作边界及相应授权。
不得修改只读旧工程和 RobotSim，不新增无关依赖，不删除文件。
门限可作为显式离线候选参数验证，不将未标定值声明为现场精度或执行保证。
