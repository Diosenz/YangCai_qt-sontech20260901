# 实测 KCF 为主的在线焊缝检测与轨迹续接规格

Category: enhancement
Status: ready-for-agent
Updated: 2026-10-24

本文件是当前对话已确认需求的正式规格，替代此前讨论稿；原讨论稿已保留备份。
分诊状态表示规格可以用于后续规划与离线工作，不构成修改生产模块、部署或运动授权。
当前已授权范围为分析、独立离线原型及回放。生产实现、现场阈值与设备闭环仍需后续落实。

## Problem Statement

用户在最新在线纠偏结果中发现：正常精定位或辅助精定位尚可，但涉及参考平面、
交线、反光、遮挡及预焊点时，KCF 点可能漂移，且难以解释当前点究竟依据什么产生。

预焊点会遮挡母材接缝，其体积还会使激光条纹增加折点、弯曲或变形。若将这些
表面形状当作真实焊缝，或者在失测时反复以预测确认预测，输出可能连续却位置错误。

KCF 点轨迹用于形成 TCP 后续跟随参考，点的位置错误会直接影响焊接准确性。
当前控制链还可能以配准后的示教模型点替换原始视觉点，导致“检测得准”不能直接
推出“控制参考保持准确”。平滑、跟随成功或 TCP 与输出轨迹接近均不足以证明焊缝准确。

## Solution

最终统一使用“KCF 点”作为目标焊缝位置的结果名称，不限定底层算法。对每个结果
明确位置来源、可信状态、目标身份、可用性及其证据；始终跟踪母材接缝中心的连续延伸。

可见且经过原图几何校核的目标焊缝形成实测 KCF 点和可靠检测锚点。中心被遮挡时，
结合遮挡前可靠观测、仿真参考的相对变化及可见母材条纹进行有限续接，明确保留估计属性。
无法确认目标时不强行给出位置；预测时间或沿缝行程任一到限即不可用，恢复须经新帧确认。

TCP 跟随参考以经过验收的实测 KCF 轨迹为主。模型用于辅助约束、异常校核和有界续接，
不默认以模型拟合点替换实测轨迹。平滑与重采样对实测位置的改变量需要可追溯且受约束。

先通过独立离线回放检查规则、精度风险及证据流，再确定生产集成。区分合成真值、真实
图像观测和现场精度，分别评价检测、空间投影、控制参考处理和 TCP 执行。

## User Stories

1. 作为在线纠偏操作人员，我希望所有最终焊缝位置统一称为 KCF 点，以便理解和使用同一种输出。
2. 作为操作人员，我希望知道每个 KCF 点来自几何实测、外观跟踪、图像辅助估计、纯预测还是恢复过渡，以便判断依据。
3. 作为操作人员，我希望不可用状态被明确表示，以便不把缺测当作准确位置。
4. 作为焊接工艺人员，我希望目标始终是母材接缝中心，以便 TCP 沿真实接缝运动。
5. 作为焊接工艺人员，我希望预焊点新增的折点和弧形条纹不改变目标焊缝身份，以便避免沿凸起表面误走。
6. 作为操作人员，我希望正常可见时优先使用经过校核的真实几何位置，以便保证准确性。
7. 作为操作人员，我希望短时遮挡期间可以有限续接，以便保持目标身份和轨迹关联。
8. 作为操作人员，我希望续接依赖此前可靠检测与仿真相对变化，以便避免被仿真绝对误差拖走。
9. 作为算法维护人员，我希望续接不假设像素偏差永久恒定，以便适应相机及工件运动。
10. 作为操作人员，我希望单侧母材可见时只使用其实际提供的约束，以便不把部分观测冒充完整实测。
11. 作为操作人员，我希望多个合理候选无法区分时不切换目标，以便避免跳到更亮的反光或其他折点。
12. 作为算法维护人员，我希望目标身份综合历史、可见母材及参考方向判断，以便不只依赖相关分数或亮度。
13. 作为算法维护人员，我希望只有明确可见且几何校核通过的目标焊缝刷新检测锚点，以便避免错误自强化。
14. 作为操作人员，我希望相似度跟踪或预测不能为自身延长失测预算，以便限制长期漂移。
15. 作为操作人员，我希望预测时间达到上限时停止输出可用点，以便不无限相信旧观测。
16. 作为操作人员，我希望沿缝行程达到上限时同样停止预测，以便约束不同速度下的失测范围。
17. 作为算法维护人员，我希望行程按工件相对运动与沿缝进度定义，以便不误用 TCP 净位移。
18. 作为操作人员，我希望重捕获通过连续新曝光确认同一接缝，以便不被单帧偶然亮峰误导。
19. 作为算法维护人员，我希望重复处理同一曝光不增加恢复确认计数，以便避免重复帧制造可信证据。
20. 作为操作人员，我希望恢复过程中原始测量与过渡输出分别保存，以便看清平滑带来的位置差异。
21. 作为操作人员，我希望恢复过渡仍标为估计，以便不把过渡点误认作原图实测。
22. 作为定位维护人员，我希望仿真位姿更新保留真实检测锚点，以便不让模型修正直接拖动 KCF 点。
23. 作为定位维护人员，我希望参考版本变化不重置失测预算，以便不让参考更新为预测续期。
24. 作为操作人员，我希望仿真缺失不否决独立有效的原图测量，以便在真实证据充分时继续检测。
25. 作为操作人员，我希望依赖仿真的续接在参考缺失时降级或失效，以便不掩盖支撑条件丢失。
26. 作为定位维护人员，我希望独立焊点校验只使用独立原图几何证据，以便避免模型用自身预测证明自身正确。
27. 作为定位维护人员，我希望母材表面 ICP 的独立证据继续按自身规则验收，以便不因焊点来源限制停用有效表面定位。
28. 作为焊接工艺人员，我希望 TCP 跟随以验收通过的实测 KCF 轨迹为主，以便检测准确性传递到执行参考。
29. 作为控制维护人员，我希望模型处理不能默认覆盖实测轨迹，以便模型仅承担辅助角色。
30. 作为控制维护人员，我希望平滑、重采样及模型约束造成的位置变化可量化，以便发现控制参考对实测的偏离。
31. 作为调试人员，我希望原始像素、投影点、最终 KCF 点、释放参考和实际 TCP 分层保留，以便定位误差来源。
32. 作为调试人员，我希望通过曝光时间、观测身份、参考版本及坐标系关联这些记录，以便追溯同一观测的后续用途。
33. 作为验收人员，我希望按同一工件坐标及同一沿缝位置比较视觉参考与随后经过的 TCP，以便正确处理相机前视时序。
34. 作为验收人员，我希望使用独立焊缝真值评价准确性，以便不将 TCP 自身轨迹当作真值。
35. 作为验收人员，我希望同时看到可用率、不可用区间、预测误差和恢复误差，以便不因剔除困难帧得到虚假的好结果。
36. 作为调试人员，我希望真实归档与合成场景明确区分，以便不将简化时序的结果当成现场能力。
37. 作为项目维护人员，我希望先独立离线验证并保留生产模块边界，以便在修改在线行为前形成可审阅证据。

## Implementation Decisions

### 已确认行为契约

- KCF 点是统一结果名称，算法来源、可信状态、位置可用性及独立校验资格分别表达；不以算法名代替证据判断。
- 目标是母材接缝中心，不直接跟随预焊凸起轮廓。焊枪是否随凸起调整高度属于独立控制议题。
- 处理流程依据实际证据分流，不要求先准确分类所有反光、遮挡和预焊点。
- 几何实测可以建立或刷新检测锚点；外观相似、部分图像约束、纯预测和恢复过渡不能单独刷新可靠锚点或重置失测预算。
- 无可靠历史锚时，不能仅依靠仿真绝对交点制造可靠检测；但可以由独立有效的新原图观测重新建立锚点，所需确认条件待定。
- 相似度可支持短时续跟，但不因相关分数高而自动获得独立几何资格。
- 单侧母材只约束可观测方向；完整位置中的预测成分仍须保留。近乎平行等弱约束不能冒充稳定完整测量。
- 多候选无法确认目标身份时，保持有限预测或不可用；不能按亮度、相关分数或距 CAD 最近简单切换。
- 预测采用经过时间与沿缝行程双上限，任一到限不可用；预测或参考更新不能自我续期。参考失效和位置不确定性还可能使结果更早失效。
- 参考变化按版本重新建立关系，保留真实锚点，不将模型跳变解释为真实接缝瞬时移动。
- 重捕获经连续新帧确认目标身份后恢复，允许有界过渡；原始测量与最终过渡输出分别保留，过渡输出仍为估计。
- 仿真缺失不单独否决独立有效的原图实测；依赖仿真的续接应降级或失效，空间投影仍要求有效标定和曝光姿态。
- 独立焊点校验仅使用独立原图几何确认的焊缝点，不使用模型辅助估计、外观续跟、纯预测或恢复过渡形成循环自证；母材表面定位保留自身验收路径。
- 控制参考以验收通过的实测 KCF 轨迹为主，模型辅助而不默认替换。估计点是否允许驱动 TCP、如何降速或停止，尚未由此规格决定。
- 不以平滑、TCP 跟随成功或预测仍在预算内证明位置准确。误差约束尚待具体化，不把演示限值直接变为现场参数。

### 模块与修改边界

- 当前交付只整理规格与离线材料，不修改线上检测、空间投影、控制参考生成、通信或设备行为。
- 后续检测行为需与 Vision 的既有输出契约协作；跟随参考策略需与 Control 维护者协调。明确目标不等于本次已获得修改这两个模块的授权。
- DigitalTwin 负责提供参考几何、状态及版本边界；Localization 保留定位和独立表面验证职责。不得将检测或控制问题借机混入这些模块。
- UI 呈现来源、可信状态和诊断证据，重型算法及运行循环保留在模块执行边界，不放入 UI 线程。
- 不修改旧工程和 RobotSim，不新增生产模块、第三方依赖或全局共享状态。
- 在现有观测结果、曝光上下文和控制记录边界上演进可追溯信息；具体类型、持久化字段和接口签名尚未确定，不预先承诺新的协议。

### 待实施设计确定的数值与策略

- 可靠锚点建立条件、模板更新资格、模板更新时机及其与锚点更新的区别。
- 双预算的现场数值、沿缝计量参考，以及额外失效条件和误差/不确定性约束。
- 重捕获确认帧数、身份冲突门限、恢复限幅、大偏差重捕获和重新建立锚点的条件。
- 参考重对齐失败、弱几何约束及长时间缺失的处理。
- 平滑、重采样和模型约束允许改变实测位置的范围；模型与实测冲突时的具体处理。
- 现场独立焊缝真值、误差指标和最大横向偏差：用户明确为“待定”。

## Testing Decisions

### 建议的主要验收边界

优先复用现有在线观测处理边界：输入按曝光关联的图像、必要空间上下文、参考信息及有序历史，
观察最终 KCF 结果和公开诊断输出。保持一个主要行为验收入口，不为每个内部阶段另造测试接口。

这个具体测试边界是根据现有代码与回放提出的实施建议，尚未获得用户单独确认；本次保存不将其
描述为已确认的接口设计。控制参考与 TCP 的验证使用已有控制回放及坐标契约能力扩展，避免把
检测单元测试伪装成设备闭环。

### 测试原则及先例

- 检查外部可见的位置、来源、可用性、锚点身份、失效和恢复行为，不断言内部函数调用次序、私有权重或具体算法实现。
- 沿用已有图像几何、KCF 退化/恢复、在线纠偏回归、坐标转换与运行记录测试的组织方式；优先复用正式入口及已归档图像。
- 需要覆盖 Vision 观测行为、DigitalTwin 参考版本/缺失契约，以及后续经授权的 Control 参考生成行为；涉及三维链时复用坐标契约验证。
- Localization 独立表面验证保留回归检查，确认估计焊点不参与独立焊点自证，且不误伤有效母材表面证据。
- 真值和场景标签只进入评分端，不能泄露给候选提取及状态决策。合成结果不推导现场毫米精度。

### 场景与可观察验收条件

| 场景 | 应观察到的行为 |
| --- | --- |
| 正常可见的母材接缝 | 输出经几何校核的实测点，保留原始位置及来源 |
| 预焊点遮挡并引入折点/弧线 | 不改跟踪目标；可见母材支持估计，估计不刷新可靠锚 |
| 反光竞争、多个合理候选 | 不按亮度切换；无法确认时有限预测或不可用 |
| 仅单侧母材 | 输出仍带估计属性，未观测分量不伪装成实测 |
| 完全遮挡或图像不足 | 有锚且支撑条件有效时有限预测；无锚不能凭 CAD 建可靠点 |
| 时间或沿缝距离分别到限 | 任一上限独立触发不可用，不因预测输出延长 |
| 重复曝光 | 不增加恢复确认计数，不制造新观测 |
| 重新看见目标 | 连续新帧确认同一接缝后恢复，原始点与过渡点分开 |
| 模型位姿/参考版本突变 | 不直接拖动输出，不重置失测预算，保留真实锚点 |
| 仿真缺失 | 独立有效的原图实测仍可通过；依赖参考的续接降级或失效 |
| 预测偏离真实轨迹但仍在预算内 | 报告实际误差，不因未超时就认定准确或可执行 |
| 模型与实测不一致 | 保留实测及处理前后差异，不默认用模型替换；具体降级动作待定 |
| 空间转换与外轴运动 | 曝光姿态关联正确，坐标转换一致，避免重复偏移 |
| 前视观测与 TCP 后续经过 | 按共同工件坐标和同一沿缝位置比较，不要求同时刻坐标相等 |

### 评分与阶段验收

同时报告实测/估计/不可用比例、失效区间、可用点误差、最大误差、恢复过渡误差以及控制参考改变量。
有现场真值后分别验收图像、投影、控制参考与 TCP 跟随误差；没有真值时只报告诊断一致性。
最近折线距离可用于诊断，但不能替代同一沿缝位置对应的真实误差。

当前已有九场景220帧合成原型、真实单帧精定位回放和三批控制记录审计。这些是设计证据，
不是本规格的生产验收通过记录。生产 C++/Qt 变更最终仍需 Windows/VS2022/MSVC 及必要运行验证。

## Out of Scope

- 本次直接修改或部署生产检测/控制策略，自动发送设备运动指令。
- 自动创建 GitHub Issue、提交、推送或合并；项目使用本地 Markdown 事项跟踪。
- 确定焊枪对预焊凸起的高度调整，失测后停机、减速、退让和焊接工艺动作。
- 自行确定实际横向误差公差，或把原型参数当作现场安全/精度参数。
- 用 TCP 轨迹、CAD 或预测点充当真实焊缝真值；用稀疏真实图像声称完整遮挡闭环已验证。
- 全面重写 KCF、引入新检测网络、重构所有模块或处理无关 legacy 兼容问题。
- 修改其他开发者负责的生产模块而不确认协作边界，或修改只读旧工程及 RobotSim。
- 将“来源可信”直接等同于“允许执行”；估计点的控制资格仍待定义。

## Further Notes

### 已核实的现状与局限

代码和数据审计固定于远端提交 `430aaa204fd5319dd7f697d3de2b4e1faddbb06f`。
本地工作树版本与该快照不同，后续实现前应重新确认最新代码，不假设旧工作树与审计快照一致。

当前活跃路径优先原图几何，降级时使用经过身份校验的 KCF 结果；部分旧版引导、滤波和
连续性逻辑不在该活跃路径中。不能把配置名称或旧代码存在当作运行能力的证据。

当前外层仍可能因缺少同帧仿真参考跳过检测；当前控制轨迹 ICP 可用变换示教点替换释放点。
这是与目标策略需要处理的行为差异，不是本次已修复的问题。缺测时 UI 的参考交点显示也
不等同于独立原图测得的 KCF 点。

真实会话含检测诊断、实际机器人轨迹、跟随目标和 ICP 记录，但跨层唯一观测关联及显式
沿缝参数不足，不能自动将每个控制点追溯到唯一曝光。真实连续预焊点过程仍缺充分回放证据。

合成压力场景曾在预算内出现约4.9px预测误差，说明预算不等于精度保证。原型的0.9秒、2mm、
3帧确认、2px过渡及8px身份门限均为未标定候选，不能直接采纳为生产阈值。
