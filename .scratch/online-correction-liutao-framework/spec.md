# 基于刘涛论文框架的在线焊缝跟踪与纠偏规格

Category: enhancement
Status: ready-for-agent
Created: 2026-10-26
Updated: 2026-10-26

本规格综合本轮 Q1～Q11、用户补充及测试边界确认。ready-for-agent 表示可据此开展实施与验证工作，不表示功能已经实现、现场精度已经通过，也不自动授权运行真实机器人、起弧或部署。此次 to-spec 操作只发布规格和跟踪事项。

## Problem Statement

用户期望在线纠偏在关闭工件在线点云 ICP 的情况下，仍能准确、稳定、连续地给出目标焊缝位置，并使 TCP 随后沿检测形成的空间轨迹运动。在线点云 ICP 用于进一步改善仿真工件对齐，不能成为基础焊缝跟踪良好的必要条件。

实际测试中，可见接缝仍然存在，程序却可能持续拒绝有效观测、长期输出历史估计，绿色 KCF 点逐渐偏离真实焊缝。此前只改善点是否持续显示、局部门限和历史续接，未充分保证位置准确及可见后的重新识别。对于预焊点，用户要求经过遮挡的整个过程保持合理且稳定的焊缝位置，不能跟随凸起表面的附加折点，也不能通过持续显示错误点掩盖失测。

本轮已核对的 15:26 保存记录中，截图对应第 42115、43911 帧，最后实测锚点均为第 41713 帧；此后约 94.5 秒、814 个处理帧未刷新实测锚点，却持续给予估计输出跟随资格。第 44525 帧的输出与原图几何候选相差约 102 个原图像素。候选不是独立真值，这些记录证明持续输出与准确性脱节，不构成已经验证的根因结论。

两篇相关论文给出了相关滤波、虚实融合、模板更新和遮挡恢复框架，而当前正式在线路径主要采用原图几何测量、身份验收与连续估计，不能因类名或界面仍称 KCF 就视为已经实现论文方法。用户已明确要求直接以刘涛在杨家林工作基础上的方案为主要实现目标。

同时，严重失测需要停焊并使机器人受控停止，但不能因门限过严，把肉眼清晰可见且本可检测的正常场景误判成失测，导致正常测试和焊接无法进行。

## Solution

以刘涛论文的三模板、HOG／灰度双特征联合训练及相应跟踪机制为主要实现目标，结合仿真先验参与的位置估计、模板更新和遮挡恢复，重建在线焊缝跟踪主线。杨家林论文用于理解基础机制和对照，不要求先完成其独立实现。

持续跟踪目标是母材接缝中心，包括其经过预焊遮挡时的连续延伸。当前可靠图像观测主导位置校正，历史信息维持连续性，仿真信息提供可信的位置、方向、形状或运动参考；这些参考分别判断，不能因仿真位置不准而整体弃用，也不能默认仿真方向必然正确。

分别判断跟踪输出、模板更新、独立几何证据及控制跟随资格。完整双侧母材拟合不作为所有用途的统一前提。普通预焊遮挡期间继续合理估计，重新确认同一真实焊缝后尽快纠正位置；机器人运动平滑由空间轨迹和控制环节承担。

TCP 按实际运动进度消费前置检测形成的空间轨迹。示教与轨迹匹配提供姿态、方向和适当平滑，不能长期把正确检测拉回原有示教位置。持续严重失测且可用可靠前视轨迹耗尽时，进入停焊、机器人受控停止的作业停止流程；重新检测到焊缝不自动恢复运动。

验收分别覆盖位置准确性、连续稳定性及最终跟随效果。当前阶段检测轨迹和 TCP 跟随轨迹相对独立真实焊缝参考的平均位置误差分别不超过 2 mm、最大位置误差分别不超过 5 mm，预焊段单独报告；这些数值不直接作为逐帧拒绝或停机门限。

## User Stories

1. 作为在线纠偏操作人员，我希望直接采用刘涛论文的跟踪框架作为主要目标，以便摆脱仅围绕旧门限和历史续接反复修补的方式。
2. 作为操作人员，我希望关闭工件在线点云 ICP 后仍有良好的焊缝跟踪，以便基础能力不依赖工件位姿不断刷新。
3. 作为操作人员，我希望能区分工件在线点云 ICP 与示教轨迹匹配，以便不混淆不同开关的作用。
4. 作为操作人员，我希望正常清晰可见的接缝能持续被定位，以便不会因不必要的验收条件丢失输出。
5. 作为操作人员，我希望反向扫描阶段稳定获得正确焊缝位置，以便后续起点与初始轨迹可靠。
6. 作为操作人员，我希望正式焊接阶段连续跟踪同一目标焊缝，以便 TCP 跟随位置始终具有一致含义。
7. 作为焊接工艺人员，我希望目标保持为母材接缝中心，以便预焊凸起上的条纹变化不会改变焊接目标。
8. 作为操作人员，我希望经过预焊前、遮挡中和离开后的全过程都有稳定合理的 KCF 点，以便普通预焊区域不造成跟随中断。
9. 作为操作人员，我希望反光产生竞争条纹时仍能保持目标身份，以便不会跳到更亮的错误条纹。
10. 作为算法维护人员，我希望当前、历史和仿真模板共同参与跟踪，以便兼顾当前外观、连续性和遮挡时的先验支持。
11. 作为算法维护人员，我希望 HOG 与灰度特征通过论文的多核框架联合利用，以便避免以固定结果平均冒充联合训练。
12. 作为操作人员，我希望正常可靠观测能更新模板，以便目标外观变化后仍能继续识别。
13. 作为操作人员，我希望预焊或反光中的异常实拍外观不会污染可信模板，以便离开干扰后能恢复正确识别。
14. 作为操作人员，我希望仿真模板参与遮挡后的恢复，以便不会只依靠长期冻结的旧外观持续漂移。
15. 作为操作人员，我希望工件实际摆放与仿真位置不同仍能检测，以便适应现场装夹和摆放误差。
16. 作为算法维护人员，我希望仿真位置不准时仍能利用有效斜率与局部形状，以便保留仍然有用的先验信息。
17. 作为算法维护人员，我希望位置、方向、形状和运动参考分别评估，以便一种信息失效不会错误否决全部信息。
18. 作为操作人员，我希望可靠当前观测主导位置校正，以便结果不会长期被仿真绝对位置拉偏。
19. 作为算法维护人员，我希望可以用已确认观测估计局部虚实偏差，以便仿真辅助适应真实工件，但不把旧偏差视为永久真值。
20. 作为操作人员，我希望缺少完整双侧母材拟合时仍能利用有效跟踪结果，以便局部几何困难不等于所有输出都失效。
21. 作为定位维护人员，我希望预测与外观跟踪不冒充独立几何证据，以便模型不会用自身预测证明自身准确。
22. 作为操作人员，我希望遮挡结束后迅速接回同一条真实焊缝，以便旧预测不会持续阻止恢复。
23. 作为操作人员，我希望可靠新定位能尽快纠正错误位置，以便不会为了显示平滑而长期保留偏差。
24. 作为焊接工艺人员，我希望机器人运动单独得到平滑处理，以便位置纠错不会直接造成 TCP 突跳。
25. 作为操作人员，我希望界面持续显示 KCF 点并保留来源和可信状态，以便知道当前是观测、跟踪还是估计。
26. 作为操作人员，我希望绿色 KCF 标记保持一致，以便延续已确认的界面使用方式。
27. 作为控制维护人员，我希望检测空间轨迹主导位置修正，以便正确检测不会在后续链路被原示教轨迹覆盖。
28. 作为控制维护人员，我希望按运动进度消费前置检测点，以便机器人不会追逐不属于当前 TCP 位置的最新图像点。
29. 作为控制维护人员，我希望示教轨迹保留姿态和方向支持，以便准确贴缝同时满足焊接工艺需求。
30. 作为调试人员，我希望图像、曝光姿态、空间点、释放参考和后续 TCP 记录可关联，以便辨别检测、投影和执行的误差来源。
31. 作为操作人员，我希望普通预焊和短时反光不会触发严重失测停机，以便正常测试与焊接能够连续进行。
32. 作为操作人员，我希望严重失测由多种证据综合判断，以便单个门限或若干帧拒绝不会导致误停。
33. 作为操作人员，我希望可信前视轨迹仍可用时继续合理跟随，以便短时观测困难不会浪费已获得的有效检测。
34. 作为操作人员，我希望持续无法可靠定位且可靠前视轨迹耗尽时停止作业，以便不再凭无限期预测继续焊接。
35. 作为操作人员，我希望停止作业同时停止焊接并使机器人受控停止运动，以便不会只停纠偏发送而继续沿原轨迹焊接。
36. 作为操作人员，我希望看到停止请求和设备确认的区别，以便上位机停止更新不会被误认为设备已经停止。
37. 作为操作人员，我希望严重失测停止后由人工确认再启动，以便重新检测到目标不会自动触发运动。
38. 作为验收人员，我希望检测轨迹和 TCP 跟随轨迹分别满足平均 2 mm、最大 5 mm 的目标，以便定位准确性与执行准确性都得到检验。
39. 作为验收人员，我希望预焊段独立报告误差、连续性和恢复表现，以便困难区间不会被正常区间的统计掩盖。
40. 作为验收人员，我希望使用独立焊缝参考而不是当前跟随 TCP 或 CAD 作为真值，以便避免错误轨迹相互印证。
41. 作为验收人员，我希望缺测、拒绝和困难帧保留在报告中，以便不能通过删除失败样本获得好看的精度结果。
42. 作为维护人员，我希望能从同一份会话输入复现生产链路行为，以便在不连接真实设备时检查恢复、误停和停止命令。
43. 作为维护人员，我希望测试覆盖参考变化、重复曝光和会话切换，以便旧目标或旧预测不会污染新会话。
44. 作为项目协作者，我希望改动保持模块与线程边界并保留历史证据，以便算法恢复不会引入无关重构或破坏协作成果。

## Implementation Decisions

### 算法主线与证据职责

- 先查找并核实本机师兄已有 SontechWorks 实现及当前 Qt 已迁移能力，建立论文机制、来源版本、实际调用链与当前差异的对应关系。优先复用、适配和接通经过核实的实现，仅为证据明确的缺口编写新代码；不能把论文算法默认当成全部从零实现。旧工程只读，新增或修改内容仍落在当前项目的对应模块。
- 直接以刘涛方案为主要实现目标：当前实测模板、历史模板与仿真模板，以及 HOG／灰度特征构成三模板双核联合训练；核权重和模板系数的联合学习不是对三个输出固定取平均，也不是只切换配置名称。
- 参考刘涛的响应置信统计、模板更新和仿真先验参与的 Kalman 估计机制。正常更新、异常防污染和仿真辅助恢复必须形成完整调用链，不以模板冻结加无限历史外推替代论文目标。
- 具体统计窗口、学习率、噪声协方差、搜索范围和恢复确认参数由代码核对、回放与现场证据确定。论文公式、文字与现代码冲突时明确记录和验证，不能机械照抄或静默选择。
- 本轮不是继续默认扩充当前几何验收与历史续接主线。已有几何提取可作为辅助校核、观测补充和独立证据来源；不进行无关重构或删除旧实现。
- 跟踪输出、模板更新、独立几何证据和控制资格分别表达。正常相关观测不必每帧通过完整双侧母材拟合；允许更新跟踪模板不等于可以刷新独立几何锚点或参与独立 ICP 验收。
- 无法直接观测接缝时保留估计属性。预测输出不能反过来作为新的独立测量给自身无限续期，也不能污染可靠实拍模板。

### 仿真失配与恢复

- 仿真绝对位置、条纹方向、局部形状和运动趋势分开评估。工件摆放失配时可以继续利用可信斜率和形状；方向属于可容错的辅助先验，不是必须服从的硬约束。
- 可靠当前图像观测主导位置修正，允许已确认观测支持局部虚实偏差估计；不能因偏离仿真绝对位置而持续拒绝，也不能采用固定融合长期拉偏。
- 普通预焊阶段持续估计母材接缝中心，不把预焊表面额外折点作为新的焊缝目标。能够使用当前有效条纹与结构时，不能无视当前图像而只沿旧位置外推。
- 重新确认同一真实焊缝后尽快纠正位置。重捕获需排除竞争目标，但不能被错误历史预测持续否决；原始观测与平滑控制参考分开保留。
- 图像层位置估计的纠错与空间轨迹、机器人运动的平滑分别承担职责。禁止为保持界面平滑而让错误检测位置长时间缓慢回归。

### 空间跟随、模块及线程边界

- 当前生产焊缝检测边界承担三模板双特征跟踪、模板生命周期、融合及重捕获；UI runtime 负责冻结曝光上下文、模块组装、结果运输与显示；现有控制边界负责前视轨迹消费、运动平滑和控制资格；RobotComm 负责真实命令及反馈语义。DigitalTwin 提供仿真数据，Localization 保留工件位姿配准边界。
- 对 Vision、Control 仅作完成本规格所必需的检测和跟随改动，不因它们的名称将定位或数字孪生算法归入其中；保持单向显式依赖，不新增生产模块。
- 前置检测点使用曝光对应的标定、机器人与外轴姿态转换到一致参考系，不能以收结果时的最新位姿替代。会话、曝光和参考版本变化需要明确隔离。
- 检测空间轨迹决定位置修正，示教与轨迹匹配提供姿态、方向和适当平滑；匹配后仍需验证没有把正确检测拉回原示教轨迹。
- 当前 UI 工件在线点云 ICP 与控制层轨迹 ICP 是不同功能。基础检测能力不能以前者开启或写回成功为前提；关闭工件在线点云 ICP 是主要验收配置。
- 图像层连续估计与控制层缺测参考预测属于不同来源，必须检查其组合行为，不能只治理一个入口后让另一入口无限续走。
- UI 持续显示同一业务 KCF 输出，标记延续已确认的绿色，通过文本和诊断区分观测、跟踪、估计及低置信状态；显示点与控制输出的几何关系可追溯，低置信显示不自动授予执行资格。
- 保持现有 Qt Widgets、CMake、VS2022／MSVC 技术约束。重型跟踪、机器人通信和定位不进入 UI 线程；退出、停止和会话撤销须可安全回收，不新增未经必要性论证的依赖。

### 严重失测与停止作业

- 严重失测不是单个门限失败、缺少完整几何、仿真失配、没有独立实测资格或连续若干帧拒绝的同义词；平均／最大误差验收值不直接用于在线停机。
- 普通预焊和短时反光利用现有有效信息持续跟踪。严重失测判断综合当前图像证据、跟踪与重捕获、估计可信程度和可靠前视轨迹可用性，不能仅凭过严固定超时停机。
- 持续缺少可信定位时，先消费尚可使用的可靠前视轨迹；可靠轨迹耗尽且仍无法恢复后停止作业。已经不可用的旧点或控制层预测不得伪装成可靠队列继续支撑运动。
- 停止作业要求停焊与机器人受控停止运动，不是简单停止发送纠偏量，也不是直接断电急停。具体停弧、运动停止及确认顺序必须核对机器人端程序、通信能力与反馈；在反馈不支持时不能伪称已经完成停止。
- 停止后图像检测可以继续尝试恢复，但不因重新检测到焊缝自动恢复运动，需人工确认后重新启动。不在本轮扩建自动续焊。
- 正常可检测场景不得被误判停机、真实失测能够正确停止，两者同时作为验收要求。参数确定必须同时检验误停和漏停，不能以放宽到永不停止来通过正常测试。

## Testing Decisions

### 已确认的主要测试边界

- 用户已明确确认：复用现有 runtime 会话级集成入口，以连续原图、曝光姿态及仿真输入，驱动生产检测、真实空间投影、完整控制队列和模拟机器人通信；统一检查输出、恢复、误停及停止流程。实际 TCP 的 2／5 mm 精度另用独立焊缝真值实测。
- 优先扩展同一个最高层会话入口与统一报告，保留真实生产 worker、控制状态和队列。替身限于外部图像／仿真数据源与设备传输，不在回放器中再实现一套替代检测或控制策略。
- 最低必要输入包含有序原始曝光、曝光身份与时间、标定和当帧姿态、仿真条纹与焊缝参考及版本、机器人反馈与命令回执。实现中核对所需字段，缺失资料明确报告，不补造物理状态或重复图片冒充连续曝光。
- 真值只进入评分器。图像观测、空间点、释放参考、后续 TCP 和停止命令／回执按同会话关联，避免用同时刻最新检测点与当前 TCP 直接相减。
- 好的测试断言用户可见行为与公开接口结果：点在哪里、来源是什么、能否恢复、后续控制消费什么轨迹、何时停止以及收到什么反馈。避免断言内部函数调用顺序、私有变量或固定权重值。

### 现有测试先例与必须补足的范围

- 现有 runtime tracking flow 已有生产 worker、模拟机器人／RobotSim transport、会话切换、迟到结果丢弃和控制闭环测试，是主入口的复用基础。
- 生产 DetectorReplay 及实拍曝光回归可用于缩小算法故障和辅助比较；现有控制器状态流、前视队列和录制测试用于有针对性的补充。已有 UI 渲染测试可核对标记颜色、来源文字与低置信状态。
- 现有组合回放的一部分通过 Python 证据策略，控制回放还有局部快照范围限制；未经改造不能声称覆盖本规格的生产三模板跟踪、完整队列消费、连续控制和停止作业。
- 在主要会话入口中按需扩展连续曝光输入、设备停止请求与反馈观察及统一评分。精度和生命周期各有辅助测试，但不为每个内部子模块另建一套业务策略入口。

### 场景与外部行为验收

1. **基本检测与反向扫描**：当前接缝可见、仿真位置一致或失配，均能正常建立和保持目标；工件在线点云 ICP 关闭时完成同样流程。初始化尚无可靠目标的状态必须如实报告，不能伪造已测得位置。
2. **普通在线跟踪**：覆盖直线、圆弧、方向变化与现有工件典型接口，检查位置、连续性、来源及控制消费的一致性。
3. **预焊完整过程**：使用遮挡前、遮挡中、离开后的连续输入，检查接缝目标不变、点持续合理、不跟随凸起、模板不被异常外观拖偏、离开后恢复可靠观测；不能只测首丢后很短窗口。
4. **反光及竞争条纹**：单峰转多峰、明暗变化及更亮错误条纹时，检查目标身份和恢复表现；不能把这些普通干扰统一判成严重失测。
5. **虚实偏差**：位置偏差与方向仍有效分别构造；方向参考本身也有误差时应容错。检查可靠观测不会被仿真位置或错误历史锚持续否决。
6. **位置恢复与控制平滑**：在估计已有明显偏差后恢复清晰观测，检查定位能够纠错、后续空间控制仍平稳；原始测量、最终估计和释放参考分别保留，不能仅凭步长小就判正确。
7. **资格区分**：部分图像支持、跟踪及估计可按其真实依据输出，但不能自称独立几何；允许模板更新不代表允许用于模型独立验收，UI 可见不等于控制可执行。
8. **前视轨迹与跟随主导**：按照同一焊缝区段和运动进度关联后续 TCP，检查队列实际消费、姿态支持、平滑误差及示教轨迹没有覆盖正确检测。
9. **严重失测与误停**：逐步撤去有效观测并令位置先验失去支持，覆盖可靠队列尚未耗尽和耗尽后的行为；同一停止判据在正常、可检测反光和普通预焊场景中不得误触发。
10. **停止命令与反馈**：模拟机器人仍在运行、停止请求未确认、确认成功或返回失败，分别检查停弧和运动停止的实际协议行为、状态显示、后续命令处理以及不自动重启。软件替身成功不代替真实设备确认。
11. **时序与生命周期**：覆盖重复／倒序曝光、迟到结果、参考版本变化、会话停止与重启，检查不会刷新错误证据、拖动新会话或在停止后继续放行旧运动目标。

### 精度统计及证据充分性

- 检测空间轨迹与 TCP 实际轨迹分别相对独立取得的真实焊缝轨迹评分，目标均为平均位置误差 ≤2 mm、最大位置误差 ≤5 mm；预焊段另报并单独检查，不能仅用全程平均稀释困难区间。
- 对齐同一工件坐标、同一目标焊缝区段与沿缝对应关系，再计算有效对应的空间距离；不能用跨段全局最近点或当前 TCP 自身作为真实焊缝依据。独立示教参考必须是另行确认真实接缝的测量，不能只是当前算法跟随结果。
- 报告误差定义、参考获取方法、标定与测量不确定性、样本数量、缺测区间、估计占比、恢复过程、误停和漏停。最大误差指纳入评分样本的实际最大值，不以分位数代替。
- 原图像素误差独立统计；其数值公差尚未约定，不将 2／5 mm 直接换算成全图固定像素门限。无可靠真值的可见图像可做位置诊断，不能称为已通过毫米精度验收。
- 输出缺失或姿态／真值关联缺失须保留并标记未验证，不能静默删样本；仅有误差数值合格不能掩盖连续性或停止行为失败。
- 合成场景用于已知真值、反例和状态边界，真实连续曝光用于现场模式复现。稀疏真实图片不能冒充完整预焊连续过程，缺曝光姿态不能冒充真实三维验证。
- 最终构建与必要运行验收以 Windows／VS2022／MSVC 为准，依照仓库现有构建规则执行；本次规格发布不触发构建或真实设备运行。
