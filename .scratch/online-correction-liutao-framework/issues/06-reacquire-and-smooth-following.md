# 06: 恢复真实观测并分开处理定位纠错与运动平滑

Category: enhancement
Status: ready-for-human

**Parent:** [01 统一实施事项](01-implement-and-validate.md)。

**What to build:** 包括虚实失配的遮挡场景中，真实接缝重新可见后能够重新确认同一目标并尽快纠正估计偏差；TCP 随后按前视空间轨迹平滑跟随，不为显示稳定而长期保留错误点。

**Blocked by:** [04 仿真位置失配时仍正确定位真实焊缝](04-track-with-simulation-misalignment.md)、[05 连续跨越预焊点和反光干扰](05-cross-tack-and-reflection.md)。

## Acceptance criteria

- [x] 核实既有重捕获、模板重建、轨迹队列和跟随平滑机制，优先调整必要接入而非新建重复状态机。
- [x] 在预测已存在明显偏差后恢复可见观测，错误旧预测或仿真位置不能持续否决可靠的同目标定位。
- [x] 重捕获能够区分真实焊缝与竞争条纹，恢复参数由正常与干扰数据验证，不单纯降低全部门限。
- [x] 原始观测、最终位置估计与释放控制参考分别记录，定位能够及时纠错，不用逐帧缓慢移动错误检测点代替控制平滑。
- [x] 真实控制队列按运动进度消费前置检测点，示教与轨迹匹配补充姿态、方向和平滑，不能把正确检测长期拉回旧示教位置。
- [x] 主会话报告覆盖偏差进入、遮挡、恢复、后续控制消费全过程，检查定位恢复与模拟控制行为，不能用同时刻 TCP 与最新像素点直接比较。
- [x] 相关回归和 Windows／MSVC 验证通过，数据不足的现场精度部分保持未验证。

## Further notes

以[完整规格](../spec.md)为准。此任务是仿真失配与预焊跨越两条分支的汇合点，不涉及工件在线点云 ICP 的进一步优化。
