# 09: 会话切换与迟到数据不污染跟踪或控制

Category: enhancement
Status: ready-for-human

**Parent:** [01 统一实施事项](01-implement-and-validate.md)。

**What to build:** 使用新的论文跟踪路径时，参考版本切换、重复或倒序曝光、显式停止及人工重新启动都不会让旧模板、旧预测、旧空间点或迟到反馈带动新会话，也不会重新放行已停止的运动目标。

**Blocked by:** [03 以刘涛三模板双特征框架完成正常焊缝跟踪](03-integrate-liutao-normal-tracking.md)、[07 打通停焊与机器人受控停止的确认流程](07-confirm-controlled-stop.md)。

## Acceptance criteria

- [x] 复用当前会话、曝光身份、参考代次与在途请求隔离能力，只补齐新模板／融合状态的必要生命周期处理。
- [x] 重复或倒序曝光不制造新的独立证据或恢复确认，迟到旧结果不覆盖新目标或新的可靠观测。
- [x] 参考版本变化不直接把绝对 CAD 修正当成真实焊缝运动，也不错误刷新估计的可信依据。
- [x] 显式停止后在途图像、旧命令和迟到回执不能恢复运动资格；人工重新启动产生隔离的新会话。
- [x] 模板、偏差和预测状态的保留或失效行为有公开结果可验证，停止和线程退出可安全回收。
- [x] 通过主会话入口观察图像输出、空间参考、控制命令与 UI 状态，测试不依赖私有字段和内部函数顺序。
- [x] 与现有重复曝光、参考变化和停止／重启回归兼容，正常会话结果不被防护逻辑误拒绝。

## Further notes

遵守[完整规格](../spec.md)。本任务在正常新跟踪路径和明确停止通道上验证隔离，可与失配、遮挡和严重失测判定的开发并行；最终汇合后仍须重跑这些场景。
