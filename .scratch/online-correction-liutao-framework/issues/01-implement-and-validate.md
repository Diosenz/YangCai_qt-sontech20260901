# 实现并验证刘涛框架下的在线焊缝跟踪与必要纠偏对接

Category: enhancement
Status: ready-for-agent
Created: 2026-10-26

## Specification

完整需求、行为边界、来源、测试入口和验收条件见 [功能规格](../spec.md)。本事项是该功能的统一实施跟踪入口，不另行改变规格。

## Scope

- 核对论文机制、当前生产活跃路径和现有测试之间的差异，形成实施顺序。
- 以刘涛三模板双特征联合训练、仿真辅助融合与模板恢复为主要实现目标。
- 完成检测输出、空间投影、前视队列、控制跟随及已确认停止行为的必要对接。
- 复用用户确认的 runtime 会话级集成入口，补足连续回放、恢复、误停及模拟停止反馈验证。
- 工件在线点云 ICP 关闭时验证基础能力；真实精度按独立焊缝参考验证，平均 ≤2 mm、最大 ≤5 mm，检测／TCP 分别统计，预焊段单独报告。

## Acceptance

- [ ] 普通、反光、预焊前中后及虚实位置失配场景满足准确、稳定、连续跟踪目标。
- [ ] 已恢复的可靠观测能校正旧预测，控制平滑不通过长期保留错误定位实现。
- [ ] 跟踪输出、模板更新、独立证据与控制资格可区分，不能由预测自证准确。
- [ ] 正常可检测场景不被误停，真实严重失测及可靠队列耗尽能触发完整停止作业流程。
- [ ] 停止请求、设备反馈和实际停止状态区分，恢复图像不自动恢复运动。
- [ ] 独立真值下检测与 TCP 轨迹精度达到约定目标，困难样本和缺测区间保留。
- [ ] 通过 Windows／VS2022／MSVC 构建与相关回归，并明确现场验证仍有的证据缺口。
