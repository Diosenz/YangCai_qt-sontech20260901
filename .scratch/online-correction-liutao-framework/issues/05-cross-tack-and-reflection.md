# 05: 连续跨越预焊点和反光干扰

Category: enhancement
Status: ready-for-agent

**Parent:** [01 统一实施事项](01-implement-and-validate.md)。

**What to build:** 在仿真基本对齐的场景中，从正常焊缝进入预焊遮挡、反光竞争再离开时，KCF 点仍沿母材接缝合理连续输出，空间参考和控制消费保持可追溯；不会把预焊凸起当成新的焊缝目标，也不会把异常外观学进可信实拍模板。

**Blocked by:** [03 以刘涛三模板双特征框架完成正常焊缝跟踪](03-integrate-liutao-normal-tracking.md)。

## Acceptance criteria

- [x] 优先核实并复用已有响应统计、模板防污染和仿真模板更新机制；记录其与论文及当前路径的差异。
- [x] 完整连续会话覆盖预焊前、遮挡中、离开后的图像，体现当前、历史和仿真信息的实际作用；不能只检查首丢后的短窗口或重复单图。
- [x] 异常实拍不污染可信模板，仿真模板可辅助恢复；不能仅冻结旧模板并无限沿旧位置外推。
- [x] 在可见母材部分仍提供信息时使用其实际支持，避免跟随预焊表面附加折点或更亮竞争条纹。
- [ ] 绿色显示点、空间输出及后续控制参考连续且来源明确；估计不冒充独立几何，不因缺完整拟合就把所有用途一起拒绝。
- [x] 同时记录位置误差、估计区间和恢复表现，不以点未消失或步长小单独判定通过。
- [x] 通过生产主会话回放及相关回归；已有真实连续材料不足时明确补齐采集需求，不伪造数据或宣称已现场验证。

## Further notes
