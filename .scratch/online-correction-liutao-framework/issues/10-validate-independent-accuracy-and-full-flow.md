# 10: 完成独立精度评分与整体验收

Category: enhancement
Status: ready-for-agent

**Parent:** [01 统一实施事项](01-implement-and-validate.md)。

**What to build:** 验收人员从统一会话报告和独立焊缝参考中，分别判断检测轨迹与实际 TCP 的准确性，明确预焊前中后、恢复、误停及漏停表现，并获得 Windows／MSVC 回归和现场验证状态，不再以点持续显示代替完整效果。

**Blocked by:** [08 严重失测正确停止且正常干扰不误停](08-stop-on-severe-loss-without-false-stops.md)、[09 会话切换与迟到数据不污染跟踪或控制](09-isolate-session-and-late-results.md)。

## Acceptance criteria

- [x] 复用同一最高层会话入口，合并各分支的正常、失配、预焊、反光、恢复、严重失测和生命周期场景，保持真实生产决策和统一关联报告。
- [ ] 使用独立取得的真实焊缝参考及完整曝光上下文，按同一工件、同一目标区段和沿缝关系匹配后续 TCP；不得用当前跟随结果或 CAD 自证精度。
- [ ] 检测空间轨迹与实际 TCP 分别满足平均误差 ≤2 mm、最大误差 ≤5 mm，预焊段单独统计检查，原图像素误差另报；最大值不能换成分位数。
- [x] 缺测、困难帧和关联不充分的数据保留，报告有效样本数、未验证区间、估计占比、恢复表现、误停及漏停，不静默剔除失败样本。
- [x] 合成真值反例、实拍连续回放、模拟控制结果和实际设备执行结果分开表述；缺现场真值或真实 TCP 记录时对应精度验收保持未完成。
- [ ] 工件在线点云 ICP 关闭时完成主要验收，其他配置仅作补充，不以局部配准成功替代检测效果。
- [x] 在 Windows／VS2022／MSVC 完成构建和相关回归，覆盖 UI、生产检测、控制队列、通信停止确认与录制链路，保留可重放输入及版本证据。
- [ ] 真实停弧和受控停止能力获得实际接口验证后才宣称完成；设备运行和起弧需另有明确授权，不因本任务发布自动执行。
- [x] 核对完整规格的需求覆盖和未完成项，不把论文原型或模拟验收写成生产现场已经全部通过。

## Further notes

以[完整规格](../spec.md)为准。前置任务已间接覆盖正常跟踪、失配和恢复，因此只列最终汇合的直接阻塞。现场证据不足不能降低本任务的完成标准。
