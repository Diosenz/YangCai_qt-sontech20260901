# 04: 仿真位置失配时仍正确定位真实焊缝

Category: enhancement
Status: ready-for-human

**Parent:** [01 统一实施事项](01-implement-and-validate.md)。

**What to build:** 工件实际摆放与仿真位置不同的情况下，可靠图像观测仍决定焊缝位置，可信的仿真斜率、形状和运动信息继续辅助检测；界面点和空间跟随参考不会长期被错误仿真坐标拉偏。

**Blocked by:** [03 以刘涛三模板双特征框架完成正常焊缝跟踪](03-integrate-liutao-normal-tracking.md)。

## Acceptance criteria

- [x] 核实并优先复用既有 Kalman、虚实融合和方向辅助逻辑；辨别旧测试分支与正式生产分支，不照搬不适用参数。
- [x] 从曝光输入到最终显示、空间参考及模拟控制消费，可靠当前观测能校正位置；局部虚实偏差只由已确认依据支持，不被视为永久常数。
- [x] 分别验证仿真位置偏差但方向仍有效、方向参考也有偏差及参考缺失的行为；一种信息失效不自动否决全部可用证据。
- [x] 仿真斜率与形状是容错辅助，不能用硬方向约束或狭窄仿真位置走廊持续排除真实焊缝。
- [x] 仿真模板、坐标先验与真实观测的取样和坐标关联可追溯，不以无效仿真区域或偏差位置误训练当前模板。
- [x] 在同一主会话入口比较原实现与新行为，保留来源、定位误差与控制参考偏差，独立真值不进入算法决策。
- [x] 工件在线点云 ICP 关闭时完成上述验证，不能以写回工件位姿代替本任务效果。
