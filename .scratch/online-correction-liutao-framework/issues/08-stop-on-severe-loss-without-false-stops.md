# 08: 严重失测正确停止且正常干扰不误停

Category: enhancement
Status: ready-for-human

**Parent:** [01 统一实施事项](01-implement-and-validate.md)。

**What to build:** 普通反光、预焊和可检测焊缝持续通过；当有效定位持续丢失、恢复失败且可靠前视轨迹耗尽时，真实生产会话触发停焊和机器人受控停止流程，而不是继续凭图像层或控制层的无限预测运动。

**Blocked by:** [06 恢复真实观测并分开处理定位纠错与运动平滑](06-reacquire-and-smooth-following.md)、[07 打通停焊与机器人受控停止的确认流程](07-confirm-controlled-stop.md)。

## Acceptance criteria

- [x] 基于已验证的跟踪、恢复和停止通道，复用现有队列及作业状态，避免平行创建互相矛盾的停止判定。
- [x] 严重失测综合当前图像、重捕获结果、估计可信程度和可靠队列，不能由单一门限、缺完整几何、仿真失配或若干帧拒绝直接触发。
- [x] 可靠前视轨迹仍可用时按契约继续消费；耗尽且仍无法可靠恢复时进入完整停止流程，低置信显示不自动给予运动资格。
- [x] 同时约束图像连续估计与控制层缺测参考预测，不能由另一条预测入口为严重失测无限续期。
- [x] 正常、可检测反光与普通预焊会话不误停，真实失测会话能停止；两类场景共用同一套明确参数，不以永不停止换取防误停。
- [x] 平均 2 mm／最大 5 mm 仅作验收目标，不直接成为逐帧或停机门限；具体参数、依据和权衡记录在报告中。
- [x] 测试覆盖队列尚可用、耗尽、恢复成功及停止未确认／确认失败；恢复图像不自动恢复运动。
- [x] 主会话结果明确显示状态、原因、停止请求及反馈，保留误停与漏停样本并通过相关回归。

## Further notes

以[完整规格](../spec.md)为准。这里的严重失测是定位信息不足，不是把算法自身的过严拒绝规则重新命名为失测。
