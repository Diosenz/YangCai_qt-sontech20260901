# 03: 以刘涛三模板双特征框架完成正常焊缝跟踪

Category: enhancement
Status: ready-for-human

**Parent:** [01 统一实施事项](01-implement-and-validate.md)。

**What to build:** 操作人员在正常可见焊缝上使用刘涛三模板、HOG／灰度双特征联合训练路径，得到持续正确的绿色 KCF 输出，并形成后续空间跟随参考。优先接通当前 Qt 和师兄已有实现，不能把类名或模式切换当作论文机制已经生效。

**Blocked by:** [02 贯通可重放的正常在线纠偏会话](02-replay-normal-session.md)。

## Acceptance criteria

- [x] 根据前置核实结果复用或适配既有多核、双／三模板能力；新增算法仅针对有证据的缺口，并记录不能复用的原因。
- [x] 当前实测、历史与仿真模板以及 HOG／灰度联合学习实际进入正式在线调用链；不以固定输出平均代替联合训练。
- [x] 对论文公式与既有算法的关键差异作核对，保留来源和采用理由；不机械复制未验证的公式或旧参数。
- [x] 从正常反向扫描到正式在线的清晰焊缝会话，输出可见点、来源与空间轨迹，并被真实控制队列消费，模拟通信可观察相应命令。
- [x] 工件在线点云 ICP 关闭时正常跟踪成立，模板更新与输出不会不必要地要求每帧完整双侧母材拟合。
- [x] 保持独立几何证据与普通跟踪输出的区别，UI 仍采用绿色 KCF 标记；新路径不破坏其他用途或模块线程边界。
- [x] 在主会话入口与原实现使用同一输入比较，保留全部失败与结果，完成相关 Windows／MSVC 回归。
