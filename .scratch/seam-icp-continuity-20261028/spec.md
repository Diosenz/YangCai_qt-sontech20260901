# 焊缝检测与工件在线 ICP 刷新连续性修复

## Problem Statement

两次现场复测出现可见接缝定位偏离和预焊经过期间跳变。已复现扩大搜索残留导致清晰图像长期不再接受几何校核、母材模型到期后缺少重建，以及局部外观与外围母材约束交替输出。工件在线 ICP 写回会切换参考版本，关闭后保留已更新场景，两次现场运行不是相同初始工件位姿的开关对照。

## Solution

保持三模板 HOG/灰度、PSR 和位置融合主线。恢复清晰图像的几何校核机会，在每曝光既有计算预算内推进恢复；用当前双侧母材像素约束预焊干扰，区分完整观测、结构估计和控制资格。验证工件更新、版本切换与关闭后的继承行为，避免用仿真绝对位置作为真值或自动恢复工件位姿。

## User Stories

1. 作为操作者，我希望短暂反光后清晰焊缝及时恢复，以免错误跟踪长期延续。
2. 作为操作者，我希望长时间运行仍能重新校准母材模型，以免短片段通过而现场运行失效。
3. 作为操作者，我希望当前外围母材与局部预焊折点冲突时核对同一目标身份，以免追随预焊凸起。
4. 作为操作者，我希望真实焊缝清晰恢复后立即接纳，以免旧估计阻挡正确观测。
5. 作为操作者，我希望无当前条纹支持时撤销结构估计及其控制资格，以免历史模型自行续接。
6. 作为操作者，我希望工件版本刷新后只使用当前曝光及当前参考，以免坐标和身份混配。
7. 作为操作者，我希望关闭工件在线 ICP 后停止追加写回，同时保留已写入场景，以免产生隐式回退。
8. 作为操作者，我希望检测偏离不会把预焊附近像素误作母材参与工件修正，以免形成取点反馈。
9. 作为操作者，我希望显示估计、模板训练、独立几何和控制点资格分别判断，以免显示成功被当作测量成功。
10. 作为操作者，我希望已有正常、反光、遮挡、失测和快速恢复行为保持有效。
11. 作为操作者，我希望有可重复的命令行回放和 MSVC 验证证据，以便核对修复效果。

## Implementation Decisions

- 第一片只修复检测器几何校核与扩大搜索调度，不扩大每曝光两次精定位预算。
- 母材冲突处理保留首次可靠身份块及接缝到外围线的法向偏差；双侧持续可见时不由局部折点递推改写。候选点及当前母材约束位置同时核对原始身份，避免逐帧细小预焊变形重新标定自身。完整接缝恢复仍及时接纳；不得简单延长过期时间、强制所有正常帧经过母材模型，或加入通用像素限速掩盖跳变。
- 参考变更仍使仿真相关的几何偏差和位置融合先验失效。母材模型只包含真实像素线及真实接缝相对线的偏置，虚拟工件刷新不改变该坐标；保留模型必须逐曝光重新获得当前双侧支撑，不制造仿真坐标的跨版本桥接。此项修正规格来自同一图像只改变版本号即由1.75增至12.22像素跳变的因果对照，替代此前对所有结构模型统一失效的约定。
- 关闭 ICP 保留现有位姿、取消未发送修正；不连接现场设备，不执行真实写回或机器人运动。
- ICP 取点只接受原图母材证据；检测点不能作为独立位置真值。已用现场原图建立中央未测预焊区域仍进入取点的独立失败行为；当生产证据 `imageConstrainedEstimate` 为真时，真实表面排除范围改为检测中心[-100,+130]像素，沿用外围支撑带的中央边界。完整观测仍使用原有±24像素。采样和写后表面验证传递相同非诊断证据，虚拟表面策略、求解及写回门禁不变。
- 不更改轨迹 ICP 原始实测保留策略、不修改控制算法、不重构无关模块。
- 保留用户已有工作及文件，保存本轮基线与每片红绿结果；源文件保持 UTF-8 编码。

## Testing Decisions

用户已确认两个现有边界：生产检测器完整逐帧处理，以及运行时帧处理/工件写回接口。

- 检测器：真实捕获像素的最小可重复序列，检查位置、来源、控制资格和清晰恢复；构造历史与完整现场回放分别标注。
- 运行时：使用内存外部设备 transport，验证 ICP 开关、位姿继承、版本变化及曝光关联；不模拟内部算法来声称识别通过。
- 一次一个失败测试与最小实现。预期位置来自原图可见地标或独立构造几何，不能从待测输出反算。
- 开关矩阵包含固定初始位姿、参考版本刷新，以及关闭后继承已更新位姿；检测回放不等同于现场闭环对照。
- 回放两次现场归档，并保留缺失曝光限制。执行相关旧回归、Windows/MSVC 构建与启动检查。
- 只有现场实际轨迹与独立位置证据可确认最终 TCP 精度，像素连续性不等同于毫米精度。

## Out of Scope
