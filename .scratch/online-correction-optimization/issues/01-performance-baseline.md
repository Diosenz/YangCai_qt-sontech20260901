# 01：建立曝光到业务结果的性能基线与分段报告

Category: enhancement
Status: ready-for-agent
Execution: implemented-offline; field evidence pending

**What to build:** 使用同一实拍输入比较 Debug/Release，分离等待、算法和交付耗时，形成可重复的曝光到业务结果报告，为热点优化提供依据。

**Blocked by:** None (can start immediately).

- [x] 复用生产检测与运行时交付入口，保留曝光、会话和参考身份。
- [x] 同实拍输入 Debug/Release 对照，记录程序、源码、输入和测量环境标识；冷启动与稳定负载分开。
- [x] 输出等待、图像准备、跟踪响应、校核、训练和结果交付的可观测耗时，不以缺失值伪造零耗时。
- [x] 固定 10 s 窗口统计有效新曝光检测率，同时保留无效、预测、重复曝光及连续缺口；区间由原图和业务状态预先确定。
- [x] 计算曝光到运行时结果可用的 P95、最大延迟，并明确时钟和样本边界。
- [x] 稀疏夹具、重复图像负载、缺少连续曝光及参考外观的限制在报告中显式保留。
- [x] TDD 覆盖已确认的生产图像/结果公开边界及报告外部行为，适当回归通过，完成规范和规格审查。
